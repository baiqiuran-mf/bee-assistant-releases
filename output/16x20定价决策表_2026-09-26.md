## 三、三个方案

### 方案 A：单一价 $399（画室带上沿）

| | |
|---|---|
| **优点** | 落在 Etsy 手绘区间内（$320–430），她比价时不突兀；**"含税到门"在这个带里是稀缺卖点**——Etsy 卖家普遍写"买家自付关税"，我们包掉，是同价位里唯一的 |
| **缺点** | 掉进画工价格带，与人设冲突；6 小时工时算下来时薪 $25–40，偏低；没有上探空间，后面所有客户都被锚死在 $399 |
| **毛利** | $149–237 |

### 方案 B：分档报价——宠物 $399 / 人物 $580 / 每加一只或一人 +$120 ✅ 推荐

| | |
|---|---|
| **优点** | ① **让"画什么不一样价钱也不一样"从借口变成事实**——这句话是我们三条连发里的第 3 条，如果只有单一价，它就是拖延话术；有了分档，它是真的<br>② 入口价 $399 不吓跑，人物 $580 撑住科班人设（人物确实更难，人设里"女人最难画"正好呼应）<br>③ 加价有规则，照片来了要调整不是临时加钱<br>④ 给她一个能自己选的阶梯，选择感＝掌控感 |
| **缺点** | 报价变复杂，第一轮要说清三档；如果她只想要宠物，$399 档毛利仍是 $149–237；分档需要在站点上也能对得上，否则站内站外不一致 |
| **毛利** | 宠物档 $149–237；人物档 $330–418 |

### 方案 C：独立艺术家位 $780

| | |
|---|---|
| **优点** | 跳出画工带，毛利 $530–618；用"科班 + 6 小时起 + 含税到门"能撑住 |
| **缺点** | **这个价位在 $430–1700 的空档里，市场没有参照物**，她无从比价，容易觉得"凭什么"；冷启动阶段信任不足以支撑，大概率直接流失 |
| **适用** | 等有两三个成交案例、有作品集和评价之后再用 |

## 四、我的推荐

**方案 B（分档），但有一个硬前提：先拿到师姐站点 16x20 的标价。**

- 站点标价 **≥ $350** → 直接对齐站点价，人物档在此基础上加 $150–180
- 站点标价 **< $300 或不卖这个尺寸** → 用方案 B 的分档数字
- ⚠️ **站点标价如果是"不含国际运费"的**，不能照抄——我们要报的是含税到门，数字必须对不上

**为什么不选 A**：掉进画工带是自降身价，而且一旦锚在 $399，后面涨不上去。
**为什么不选 C**：现在还没有东西支撑这个价，强报只会当场失去她。等有案例了再上探。
