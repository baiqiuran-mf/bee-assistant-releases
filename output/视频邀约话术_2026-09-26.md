## 一、怎么开口约

### 英文成稿（4 条，顺序不能换，每条一个意思）

```
① hey — one thing
   （嘿，有件事）

② I could just show you the canvas instead of describing it.
   three minutes, camera stays on the canvas
   （我不如直接给你看那块布，省得我描述。三分钟，镜头就在画布上）

③ not that kind of call — you don't need to be on camera,
   nothing to get ready, and you can hang up whenever
   （不是那种视频通话——你不用开摄像头，什么都不用准备，想挂随时挂）

④ and if you'd rather not, just say so.
   I'll send you a voice note instead
   （你要是不想，说一声就行。那我改成给你发段语音）
```

### 中文说明

第 ① 条是铺垫（"问你个事"的等价物）；第 ② 条是核心：内容 + 时长 + 镜头位置；第 ③ 条是安全边界，三件事一次给全；第 ④ 条是退出路径。

**第 ④ 条是承诺，不是客套。** 她要是选了语音，就必须在同一时段内真的发一段语音出去——说了不做，`persona.md` 里那条"说了就必须做到，否则回溯成谎言"立刻生效，前面所有真诚会被重新解读成流程。

### 为什么这么写

**① 不像诈骗**——诈骗式视频邀约有四个特征，我们逐条反向：

| 诈骗长这样 | 我们这样 |
|---|---|
| 要求对方开摄像头（采集面孔与环境） | **"you don't need to be on camera"** |
| 要求点链接 / 装软件 | 只用 WhatsApp 原生通话，**不出现任何链接、不出现任何"下载"** |
| 强调"必须现在" | 第 ④ 条明确给了"不想就说不" |
| 露脸 + 亲昵感 | **不露脸**，且第 ③ 条一句话定性 |

**② 不突兀**——关键在 `instead of describing it`。她 9/24 问的是 **size**，我与其用文字描述一块布，不如把镜头转过去。**视频是在回答她已经问过的问题，不是另起一个新话题。** 这一句把"我想跟你视频"翻译成"我懒得打字"，动作的性质从"索取"变成"省事"。

**③ 不越界**——`not that kind of call` 这五个字是全场最重要的边界句。它一句话划掉了三层可能：不是约会、不是社交、不是那种要收拾一下才能接的电话。对女性客户，这五个字比任何解释都管用（解释反而像此地无银）。

**④ 她要的三件事，一句给全**（对应本次要求）：

- "我随时能挂" → `you can hang up whenever`
- "你不会看到我" → `you don't need to be on camera`
- "我不需要准备什么" → `nothing to get ready`

⚠️ 这三件事必须在**她答应之前**说，不能等她答应了再补。答应之后再补，她已经没有退路了，安全感归零。

**⑤ 为什么第 ④ 条给的是"语音"而不是"下次"**——给"下次"＝把球推回给她，而且是一个带时间的球（＝留余地＝追）。给"语音"＝把球留在我们这边，她什么都不用做。**门还在，但门开在东西上，不开在我们的等待上。**

## 二、时机：在哪个阶段提

### 结论（明确）

**S2a 的后半段——在"价格/尺寸已经回应过"之后、且她还在线的同一段对话里提。**

拆成三条可执行的判据：

| 判据 | 结论 |
|---|---|
| ❌ S0 刚加好友 | **绝对不提** |
| ❌ S1 破冰后、没问过价 | **不提**（次优，浪费弹药） |
| ✅ **S2a 她问价之后** | **提。但必须排在"价格已被回应"之后** |
| ❌ 她沉默后的第一击 | **不提**（见下方第 4 条否定理由） |
| ❌ 她回复变短变慢（冷淡） | **立刻撤掉提议**，退回生活分享 |

### 为什么是 S2a

**核心机制：疑虑和动作必须在同一时刻出现。**

「对面是不是真人」这条疑虑不是一开始就有的。在她问价之前，她没有损失可损失——你是真人假人对她无所谓，这时的强度接近 0。

**她打出 `How much for a 16x20?` 的那一刻，是她第一次在心里完成"我要把几百美元交给这个人"这个动作。就在同一秒，这条疑虑被激活，跳到 6.5/10。**

- 早于这一刻提视频 = **给一个还不渴的人递水**（这正是 `Alice_Day1作战卡_v2` 里那句判词：画布照在解决排名第 6 的疑虑，而排名第 1 的疑虑是"她脑子里根本没有那幅画"）。而且 S0 提视频等同于自拍——汇审已定性：对陌生客户，主动的视频/自拍是诈骗起手式。
- 晚于这一刻 = 她已经在沉默里，视频变成"你终于出现了"的补偿动作，而不是共同语境里的自然一步。

**S2a 还有一个别人给不了的东西：挂载点。** S1 时视频无处挂载，只能说"给你看看我的画室"——那是自我介绍，客户视角会读成流程动作。S2a 时她问过 16x20，视频第一次有了正当理由：**"你在问这块布多大，我给你看。"**

### 三条否定理由（同样重要，这是防止用砸的）

1. **不能把视频当成报价的替代品。** Alice 已经等了两天半。如果我们在没给出价格（或没有可信的占位理由）的情况下约视频，她的读法是"她又在给我看东西，就是不给数字"——**视频从证真翻转成拖延的装饰**，而且这一次她连"是不是真人"都不用怀疑了，直接怀疑"她是不是在绕"。这会让排名第 1 和第 6 两条疑虑同时点燃。**顺序：先回应价格（执行卡那 4 条占位 + 问画谁）→ 她回话 → 同一段对话里提视频。**

2. **沉默后的第一击不许提视频。** 她现在沉默 2.5 天。第一次开口就约视频 = **索取 + 关系升级双叠加**，会被读成"她果然在等我付钱"（`playbook7d.md` 第 5 节 Day 1 铁律：第 1 天绝口不提那幅画）。**先补报价闭环，等她有反应，再提。**

3. **她一冷淡就撤。** 回复变短、变慢、只回一个字 → 立刻撤掉视频提议（`playbook7d.md` "卡住的时候怎么办"）。视频不是目的，"让她相信你是真人"才是目的；气氛不对的时候硬上，它会反着走。

## 三、时段：一天里几点提

### 结论（明确）

**发起：她当地 20:00–22:00 ＝ 北京 08:00–10:00（次日）。**
**通话在她当地 22:30（北京 10:30）前结束。**
**硬边界：她当地 23:00（北京 11:00）——过了这条线，不再发起新视频。**

| 她的当地时间 | 北京时间 | 判定 | 能做什么 |
|---|---|---|---|
| **20:00–22:00** | **08:00–10:00** | ✅ **唯一发起窗口** | 视频邀约、画谁、价格、链接——一切索取类动作 |
| 22:00–22:30 | 10:00–10:30 | ⚠️ 可接，但必须短 | 3 分钟以内，且提前说好"就三分钟" |
| **23:00 之后** | 11:00 之后 | ❌ **硬边界** | 一个字都别提视频 |
| 17:00–20:00 | 05:00–08:00 | ❌ 不发起 | 她通勤/做饭，我们在睡或刚起，状态不稳 |
| 07:00–12:00 | 19:00–24:00 | ❌ 冷窗口 | **只给不取**。不发邀约，只放热身（见下） |
| 12:00–17:00 | 00:00–05:00 | ❌ 黑洞 | 绝对不发起。开了头无人应答＝最强反悔场景 |

### 为什么这个窗口

1. **视频是索取类动作，只能放热窗口。** 它要她点头、要她 3–5 分钟、要她腾出注意力。执行卡 v3 的纪律已经定死：北京 08–12（她当地 20:00–24:00）承担索取类，北京 19–24（她当地上午，皮质醇峰值）只放零压力闲聊。
2. **但热窗口要收窄，不能整段用。** 17:00–20:00 是她刚下班、通勤、做饭的时段，注意力是碎片；而且对应北京 05:00–08:00，我们这边要么在睡要么刚醒，**视频里状态不好比不发更糟**（她要证的就是"这个人活不活"）。
3. **上限卡在 23:00，是安全边界，不是效率问题。** 一个陌生的中国卖家在她当地接近午夜约视频——对一个女性客户，这直接点亮了她最敏感的那盏灯。而且过了 22:30，她的状态从"窝在沙发上愿意想象"滑向"该睡了，明天还要上班"，情绪驱动窗口关闭。
4. **"现在"必须是第一选项**（`playbook7d.md` W2）。所以邀约消息**本身**就发在窗口内，问的是"现在方不方便"，**不是"明天行不行"**。约到明天 = 一整夜 + 一个白天的空档，那是全剧第二贵的窗口。

### 三个时段例外（写清楚，免得临场发挥）

- **她主动在冷窗口说"我现在有空"** → 可以接。规则是"我们不在冷窗口发起"，不是"冷窗口不能接"。内容降级为 2 分钟、纯展示、不问任何问题。
- **约到了明天** → 中间必须有**一次非空触碰**顶住（W2）。可用：一段 15 秒现场拍的语音或画布短视频（实时拍摄，不受素材空目录限制）。**不许干等。**
- **11/1 之后**：全部北京时点后移 1 小时（发起改为北京 09:00–11:00）。

## 四、被拒绝了怎么接

### 判据：先分"找借口"还是"说了不"

| 她的反应 | 性质 | 用哪套 |
|---|---|---|
| `maybe later` / `I'm busy` / `can't right now` / 已读不回 | 找借口，**没说不** | **A · 撤退**（留门，但门开在东西上） |
| `I don't do video calls` / `no thanks` / `I'd rather not` | **明确拒绝** | **B · 收场**（关门，一句余地都不留） |
| 答应了，到点没出现 | 放鸽子 | **C**（不追，重约权归她） |
| 视频中途挂了 / 说"我得挂了" | — | **D**（不追问原因） |

### A · 找借口 → 撤退（3 条 + 一个动作 + 停）

```
① sure — no problem
   （好，没事）

② I'll just send you a short video of the canvas instead.
   same thing, you don't have to be free
   （那我直接发你一段画布的短视频。一样的，你不用腾时间）

③（发一段 15–20 秒现场拍的短视频，镜头对画布，不露脸，无旁白或一句就够）

④（停）
```

**为什么这么写**

- 第 ① 条不拆穿她。`busy` 是不是真的不重要，拆穿 = 追问。
- 第 ② 条是整套的核心：**把"留门"从"我的时间"改成"我的东西"。**
  - ❌ "anytime works for me" / "whenever you're free" / "no rush" / "我随时都在" / "不急你慢慢想" —— 这些留的是**我们的等待**，而等待是压力，她为了逃开这份压力只能彻底消失（`templates.md` 裁定 3）。
  - ✅ "我把那块布发给你" —— 留的是**一块布**。它放在她手机里，零压力，且触发禀赋效应（存下来的东西心理上成了她的）。
- 第 ③ 条**必须真的发**，且在同一时段内。`素材/` 目录仍是空的，所以这是**现场实时拍摄**——不违反素材红线，但反过来：**任何"配图/发照片"在别处仍一律禁止，别因为这一段破了例。**
- 第 ④ 条**停**。不带问号，不留"你什么时候方便都行"。

**门是这么留的**：那块布还在我手上，我还要接着画。她哪天想看，她自己会说"刚才那块再给我看看"。**她开口我们才动。**

**⚠️ 硬纪律：视频邀约对同一个客户，主动只提这一次。被拒之后不再主动提第二次——除非她先提。**

### B · 她明确说"不" → 收场（只两句，干净关门）

```
① totally fine
   （完全没关系）

② honestly I'm glad you just said it
   （说实话我挺高兴你直接说了）

（到此为止。没有第三句。）
```

**为什么这么写**：她说"不"之后的潜台词必须是"我不想要了"，不能是"我还想要"（撤退 vs 收场，`playbook7d.md` 第 5 节末）。`templates.md` 裁定 3 写死：她说不之后你还留余地＝你还在追，她只能彻底消失。

**⚠️ 视频场景特有的精细处（别搞错）**：这里关的是**"视频"这一件事**的门，**不是这单生意的门**。
她拒绝视频 ≠ 拒绝买画。所以收场之后照常走朋友线（生活分享、日常），只是**再也不提视频**。
→ 这是视频和付款最大的区别：付款被拒要关门，视频被拒只关这一扇。**关错门，等于把一单还在的客户推出去。**

### C · 答应了没来 → 不追（2 条，不带问号）

```
① hey — I figured you got pulled into something
   （嘿，我想你是被什么事绊住了）

② I'm back at the canvas anyway
   （我反正在画前头）
```

❌ 不问"要不要再约一次"，❌ 不问"你什么时候方便"，❌ 不重发邀请。
**重约权归她**——她想看会自己说。我们不再发起第二次。

### D · 她中途挂断 → 不追问（1 条 + 停）

```
① got it — thanks for the few minutes
   （知道了，谢谢你那几分钟）
```

❌ 不问"怎么了"，❌ 不问"是不是不方便"，❌ 不发"刚才没说完的"。
然后走第六节（结束后第一句），**去掉第 ② 条**（没有共同细节可引用，硬编就是撒谎——见第七节第 17 条）。

## 五、视频里做什么（3–5 分钟脚本）

### 硬规格（老板拍板）

**一次视频，3–5 分钟，镜头对画布，不露脸。**

### 动作顺序

| 时间 | 动作 | 说的一句 |
|---|---|---|
| **0:00–0:15** | 先说话再转镜头。手入镜，指向画布一角 | `ok — I'm just going to turn this around` |
| ⚠️ **0:15–0:30** | **第一件事：声明这块布不是她的** | `this is a 16x20 I'm in the middle of — not yours, just so you know` |
| **0:30–1:15** | 手比 16x20，旁边放一张 A4 纸做对比 | `about a sheet of paper with the margins cut off` |
| **1:15–2:15** | 敲木框听声音、手指划过布纹、转侧面给她看厚度 | `feel how rough this weave is — short fur sits on it well` |
| **2:15–3:00** | 指给她看哪一层晾了一整天 | `this underlayer sat a full day before I could go over it` |
| **3:00–3:45** | ⭐ **让她指挥镜头**：`tell me which corner and I'll turn it there` | 她指哪转哪，不解释 |
| **3:45–4:30** | 挤一点颜料 / 展示调色板 | `this is most of my day, honestly` |
| **4:30–5:00** | ⭐ **主动收尾，由我们挂断** | `I'll let you go — that's the whole tour` |

### 能说的几句话（英文成稿，够用即止，不要多说）

```
1) ok — I'm just going to turn this around
2) this is a 16x20 I'm in the middle of — not yours, just so you know
3) about a sheet of paper with the margins cut off
4) this underlayer sat a full day before I could go over it
5) tell me which corner and I'll turn it there
6) I'll let you go — that's the whole tour
```

### 为什么这么排

**① 第 0:15–0:30 那句是全场第一优先。** Alice 从没说过画谁。执行卡里已经写死一条雷：任何"你问的 16x20 就这么大"都绝对不能说——她手上任何一块布都**不可能是她的画**，一说就等于"我已经开工了，你现在欠我钱"。
所以视频里必须**主动、抢在她开口之前**声明"不是你的"。这一句把视频从"擅自开的发票"拉回"给你看个东西"。
**她若问"这是我的吗"** → 如实答：`no — this one's someone else's. yours I haven't started`。不绕、不撒谎。

**② 露手不露脸。** 手入镜是这一段的关键：**有身体 = 真人，没有面孔 = 零社交压力。** 这两个效果必须同时拿到。

**③ 3:00–3:45 让她指挥镜头，是整段视频里唯一不可替代的动作。**
2026 年，一段"不露脸、对着画布"的视频，天然带一个反噬风险：**她可能以为是预录的、甚至是 AI 生成的。** 而让她指一个角落、我们照做——**这是唯一一个只能实时发生的动作**，也是第六节第 ② 条能成立的唯一前提。这一步偷懒，整套话术作废（见文末风险点）。

**④ 只讲尺寸、材质、时间，不讲钱。** 尺寸是她自己问的（`size please`），视频直接回答了她 9/24 的第二个问题——**这是"给"，不是"推"**。
❌ 不报价、❌ 不提付款方式、❌ 不给链接、❌ 不说定金、❌ 不主动说工期（工期属于执行层信息，会启动她的理性评估；她问才答，答就照执行卡那三条口径）。

**⑤ 由我们主动收尾。** `I'll let you go` 由我们说出口，她就不用找借口挂。这直接兑现了第一节第 ③ 条承诺的"你随时能挂"——**最好的兑现方式是我们先挂。**

### 视频里的三条禁令（最容易临场破）

1. **不提问。** 不问画谁、不问挂哪、不问要不要、不问"你想看什么"。理由：提问 = 索取 = 把"只给"变成"要"；而且按探针单向阀，**我们问出来的答案不算锚**。
   唯一例外是 `tell me which corner` —— 那是给她控制权，不是向她要信息。
2. **她若自己开口说"我想画我妈""挂走廊"** → 接住，用**一句陈述句**钉住（`hallway — got it`），**不追问**。那句话她自己提的，才算数。
3. **被问到画室是谁的** → 只说 `it's my studio — the company set it up for me to paint in`。师姐、公司、团队、任务、生活费，一个字不多（见 `stories.md` 唯一口径）。

## 六、视频结束后第一句

### 英文成稿（3 条，挂断后立刻发）

```
① that was nice — thanks for watching the boring part
   （刚才挺好的，谢谢你肯看我最无聊的那部分）

② you caught the bit where the brush dragged.
   that's the underlayer still tacky
   （你正好看到笔拖不动那一下。是底色还有点黏）

③ anyway — I'll get back to it
   （行，我接着画了）
```

### 为什么这么写

**第 ① 条：承接共同体验，但不评价她。** `the boring part` 是自嘲（轻描淡写，是她的人设），不是客套。⚠️ 不夸她的声音、不夸她出现、不谢她"抽出时间"——"谢你抽时间"是客服腔，而且会把"她付出了一次"这件事摆到台面上，变成债务。

**第 ② 条是全套话术里最重要的一句：共同记忆凭证。**
它引用一个**只有"两个人同时在场"才知道的瞬时细节**。这句话的作用不是抒情，是**证真复核**——证明刚才那三分钟是实时的，不是预录、不是 AI。
（对应第七节第 17 条：**绝不编造共同细节**。视频很短或她中途挂了，第 ② 条直接删掉。）

**第 ③ 条：不立刻要钱，但也不是什么都不做。**
- 不立刻要钱：❌ 不报价、❌ 不发链接、❌ 不提定金、❌ 不问"要不要定"。
- 也不是什么都不做：做的是**把共同体验落进聊天记录**——从"一次通话"变成"一段我们俩都知道发生过什么的关系"。这个留痕是真实的资产。
- 而 `I'll get back to it`（我接着画了）是**陈述句、不带问号、不留"我等你"的余地**。它把对话结束得干净：我回到我自己的生活里去了。**这才是不追的样子。** 对照红线：它不是"我随时都在"，也不是"不急你慢慢想"，它根本没提她下一步要做什么。

### 三个变体

**变体 A · 她在视频里自己提了画谁 / 挂哪**
第 ① 条换成钉住那一句，②③ 照旧：
```
① so — the hallway. got it
   （所以是走廊。记住了）
```
⚠️ 这是**弱锚**（她自己提的才作数），但**不构成收口触发**。别在这儿往下滑。

**变体 B · 她在视频里问了价格 / 怎么付**
这是**她自己提出的执行层问题 = S2b 触发**。同一轮立刻切执行模式，按执行卡 v3 的收口时间轴走（90 秒钉住 → 锁三变量 → 给付款方式）。
⚠️ **这时候"不立刻要钱"的规则被覆盖**——她问了，我们不能装没听见。装没听见等于第二次回避报价，是这单唯一真正的死法。

**变体 C · 视频很短，或她中途挂了**
只发 ① + ③，删掉 ②。**没有共同细节就不许写共同细节。**

## 七、绝对不能说的话（视频场景红线清单）

> 前 5 条是视频**特有**的，其余是已有红线在视频场景下的落点，一并列出免得漏。

### 视频特有的硬禁忌

| # | ❌ 绝对不能 | 为什么 |
|---|---|---|
| 1 | **不截图、不录屏** | 她、画布、通话画面，一概不留。留 = 在记录她 |
| 2 | **不事后说"刚才那个是你吧" / "我听到你那边…"** | 等于告诉她你在观察她、记得她的细节。这是跟踪者语言 |
| 3 | **不赞美她的声音、长相、房间、穿着** | 一句都不行。"不评价客户外貌"是绝对红线，视频里尤其容易顺口破 |
| 4 | **不把视频当证据日后引用** | "我给你看过画室了""你当时说过要买的"——一旦引用，那次视频从礼物变成取证，前面的真诚全部回溯作废 |
| 5 | **不暗示那块布是她的** | Alice 特雷：她从没说过画谁。**"你的画""我先给你起个头"= 当场能抓到破绽的谎 + 制造她没同意过的债务** |
| 6 | **不录像存档、不对第三人复述视频内容** | 同上，且涉及隐私 |
| 7 | **不在视频里报价、收口、给链接、提付款方式** | 视频只解决一个疑虑。塞进钱，它就变成一场推销，且是她毫无防备时的推销 |
| 8 | **不在视频里要照片、要地址、要墙面尺寸** | 详细地址付款前一律禁止；其他索取破坏"只给" |
| 9 | **不主动问"画谁"** | 视频里不提问，只展示。我们问出来的不算锚 |
| 10 | **不要求她开摄像头 / 换环境 / 收拾一下** | 直接顶到诈骗警报 |
| 11 | **不露脸**（老板规格） | 被要求时一句轻松话带过（`this camera's not great for faces`），**不解释技术原因**（一解释像客服） |
| 12 | **不在她当地 23:00 之后发起；不打突袭视频** | 必须先文字约好再打 |
| 13 | **不编造共同细节** | 视频很短就没发生"笔拖不动那一下"，硬写就是撒谎，且一旦被识破不可挽回 |
| 14 | **不发视频截图当素材** | `素材/` 仍为空，任何"配图/发照片"在别处仍一律禁止 |

### 已有红线在视频场景的落点（一并核对）

| ❌ 禁止 | 出处 |
|---|---|
| 「我随时都在」/「不急你慢慢想」/「你什么时候方便都行」 | 老板拍板 + `templates.md` 裁定 3 |
| 「不着急，你想好了再说」 | 反悔批准书，`persona.md` 已划掉 |
| 「你还要吗 / are you still interested」 | 递给她一个说"不"的按钮 |
| 付款前索要详细收货地址 / 家庭住址 | 强诈骗信号 |
| 提师姐派的任务、公司、团队、赚生活费、"我的画上万" | 内部信息，漏一个字毁单 |
| 提 tariffs / customs / import tax | 没解药的时候不捅病灶 |
| 写空运或海运 | 空运＝承诺快，海运＝触发压坏恐惧 |
| 提"这块底色晾了一天"并暗示是她的画 | 执行卡已列为禁止 |
| 用一条长消息说完一件重要事 | 一律拆 2–3 条 |
| 感叹号堆热情 / dear、babe、honey | 人设红线 |

## 附则 · 视频通过后，信任层级跳档的话术含义

**老板拍板：视频通过之后，信任层级直接跳到"高"。**

| 信任层级 | 定金档 | 判据 |
|---|---|---|
| 低 | **$30 素描稿** | 只问价、没提画谁、没发照片、**没通过话** |
| 中 | **$99 占位费** | 有具体对象 / 发过照片 / 聊过 3 天以上 |
| **高** | **50%（约 $200）** | **视频通过话** ✅ / 聊过纪念意义 / 聊过 5 天以上 |

**⚠️ 但跳档改的是"能收多少"，不是"能不能收"。这两件事必须分开看：**

- ✅ 视频通过 → 定金档位从 $30 跳到 50%
- ❌ 视频通过 **≠** 触发收口。**收口仍然只能由她自己提出执行层问题来触发**（`how do I pay` / `寄到哪` / `多久能到`）。

> 理由：`playbook7d.md` 七之二那张表写死了——**"视频接通了"的价值是"信任建立，稳了"，而信任是必要不充分条件。他信任的人多了，没买过东西的也多了。**
> 视频消灭的是"对面是不是真人"（排名第 6）；它**一个字都没碰**排名第 1 的那条——"她脑子里根本没有那幅画"。**疑虑排名第 1 的还在，收口就不该发生。**

ℹ️ 另：定金仍必须说清是**抵充**不是额外收费（`products.md` 硬要求），**绝不能说成"优惠"**——说成优惠＝承认之前报高了。

## 发出前自查（每次都过）

1. 这条发出去像不像真人说的？有没有客服腔？
2. 有没有"为了不给她压力"而留的余地？（有 → 24 小时后变成我的反悔窗口，删掉）
3. 有没有把"留门"开在**我的时间**上？（`随时/不急/慢慢想` 一律是错的；门只能开在**东西**上）
4. 视频里那块布，**有没有明确说过"不是她的"**？
5. 有没有出现任何一个问号？（视频里不提问；被拒后不带问号）
6. 重要信息拆成 2–3 条了吗？
7. 现在这个北京时点，是不是在 08:00–10:00 内？她那边是不是 20:00–22:00？
8. 内部信息漏出去没有？（师姐、公司、团队、生活费、画上万）
