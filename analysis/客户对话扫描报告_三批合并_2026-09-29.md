# 七、从排行看出的四个结构性事实

## 事实 1：客户的注意力 90% 在"人"，10% 在"画"

把"画相关"的话题全加起来：

```
问/评你的画 30 + 给我画一张 14 + 你卖画吗 5 + 问技法 5 + 问工期 4 + 问风格 3 = 61 次
```

对比"人相关"：

```
夸美 314 + 表白 67 + 问在哪 67 + 日常生活（食物120 + 今天115）235 + 自我披露（工作62+运动59+饮食48+婚史38+病痛31）238 = 921 次
```

**画 : 人 ≈ 1 : 15。**

## 事实 2：唯一的高频"索取"是要照片（39 次）

其他所有高频话题，客户都在**给**（讲自己、夸你、分享生活）。  
只有"要照片"是客户在**要**。  
→ **这是客户唯一的"硬需求"，也是最有效的推进杠杆。**

## 事实 3：钱的声音出现了，但极微弱

```
说要给你钱/佣金 16 + 说我会付钱 10 + 给我画一张 14 = 40 次
问/谈付款方式 2 次
问价格 ≈ 4 次
```

**40 次"我想买"，只有 2 次"怎么付"。**

## 事实 4：宗教（59 次）已经超过"要照片"（39 次）

这是**三批合并后才浮现的**——第一批只当偶发，第二批看到 Joe 传教 5 次，第三批单批 40 次。  
合并后 59 次，排到全样本第 7–8 位。  
**👉 这是一个被严重低估的高频场景，剧本里完全没有。**
