# 话题灵感库（销售学 / 人性弱点 / 三十六计 / 男性心理 / 穷爸爸富爸爸）

> 用途：给每天的碎片清单补弹药。  
> **判据不变**：任何新话题先过四象限——对「没钱 / 不需要 / 哄你开心 / 真想买但卡住」四种人是否都起作用。  
> **只要对其中一种人有作用而对另外三种是噪音的，就只能在判别之后用，不能当日常话术撒。**

⚠️ **适用对象**：这套主要按**美国中年男性客户**的心理写。女性客户部分适用、部分相反  
（例如自拍红线对女性不成立、安全顾虑方向相反），用之前先看客户性别。

## 一、《人性的弱点》（卡耐基）→ 六个方向

**这本书的底层就一句话：让他觉得他自己重要。** 我们现在的碎片大量是"讲我的事"（早餐、画室、菜市场），  
这是必要的（否则他不认识你），但**比例要控制**。

> ### ⚠️ 2026-09-29 老板已把这节优化并移入正式规则
>
> 下面这些已**升格为通用规则**，写进了 `day1.md` 的「通用规则」区（**七天通用**）：  
> 「让他觉得他自己重要」· 多次称呼客户名称 · 记住家人名字 / 城市街道店名 · 谈他感兴趣的事 ·  
> **请教他、把他当专家** · 永远不争论 · **引导话题让他不用思考** · **对年长客户谈回忆** ·  
> 客户是资产（不买也不冷淡，但需要一个契机扭转推进的惯性）· 四条绝对禁止红线。
>
> **本文件从"建议"降为"原始出处与推导过程"**，实际执行以 `day1.md` 通用规则区为准。

### 1. 真诚地对他人感兴趣，而不是让自己有趣

> 原理：**一个月内真心对别人感兴趣所交到的朋友，比两年努力让别人对你感兴趣多得多。**

| ❌ 现在偏多的 | ✅ 要补的             |
| ------- | ----------------- |
| 我今天煮了粥  | 你那边早上一般吃什么        |
| 我的画室很乱  | 你工作的地方是什么样        |
| 我去过美国   | **你去过哪些地方，最喜欢哪个** |

**⚠️ 硬指标**：**一天里他说的字要比你多。** 今天他说的多，你就赢了。

### 2. 记住并使用他的名字（宠物名字 > 他的名字）

> 原理：**对任何人来说，自己的名字是全世界最好听的声音。**

- **宠物名字是最高优先级**。他一说，当天就要用回去，第二天还要自然用一次。
- 家人名字（他说过"我妈""我女儿"）也要记。
- 城市名、街道名、他提过的那家店。

📌 **建议**：每个客户的档案里，**宠物名字单独一个字段**，话术里 `{pet}` 自动替换。

### 3. 谈论他感兴趣的事

- 他提过的任何细节，后面都能捡回来——**捡回来说是最强的"被重视"信号**。
- 例：他三天前随口提"我周末钓鱼"，你第四天问"周末钓到了吗"。

### 4. 让他感到自己重要——**请教他**

> 原理：**让他当专家，他会喜欢你。**

可聊的具体话题：

- 「你们那边这个词怎么说？我翻译软件给的答案一看就是机器翻的。」
- 「这个东西在美国一般怎么处理？我好奇很久了。」
- **他的专业领域**：「你做这个多久了？外人看起来是不是完全不是这么回事？」
- 「你那边现在是几点？我每次算时差都要想半天。」

⭐ **请教是零成本的给**：他不费力气就有成就感，而我们什么都没损失。

### 5. 让他多说，你少说

- **陈述句 + 留白**，比问句更能让人开口。
- 他回了一句短的，不要马上接一大段——**让他把话说完**。

### 6. 永远不争论

- 政治、宗教、中美比较——**一律不接**。他提了，就轻轻转开。
- 他说错了一个关于中国的事实，不要纠正（纠正＝让他丢脸＝他从此不说了）。

## 二、《三十六计》→ 哪些能用，哪些是红线

⚠️ 声明：这里用的是**博弈结构**，不是骗术。凡是需要撒谎才能成立的计，**一概不用**——  
撒谎一旦被戳穿，信任归零，而信任是这门生意唯一的资产。

| 计               | 用法             | 对应话题 / 动作                                           |
| --------------- | -------------- | --------------------------------------------------- |
| **欲擒故纵**（第十六计）  | 逼则反兵，走则减势。紧随勿迫 | ⭐ **他不回就退，退了他才会好奇。** 严禁追问「你还要吗」                     |
| **以逸待劳**（第四计）   | 不主动消耗，等他来      | ⭐ **只给不取**：发构图、发调色后的照片，不问他任何问题                      |
| **抛砖引玉**（第十七计）  | 先给小的，引来大的      | ⭐ **$30 素描稿**、**勾一张小构图**、**发草图**——都是砖               |
| **反客为主**（第三十计）  | 让他觉得是他在主导      | ⭐ **让他纠正你**：他纠正的时候，他在主导                             |
| **树上开花**（第二十九计） | 借势让自己好看        | 师父洪瑞生、师姐的画舍、去过美国看展——**都是真的**，但要自然带出，不炫耀             |
| **假痴不癫**（第二十七计） | 装不懂，让他来教       | ⭐ **请教他**（见上）。装不懂比装懂安全一百倍                           |
| **苦肉计**（第三十四计）  | 人不自害，受害必真      | ⚠️ **只限自嘲、展示小失败**（"我毁了两次"）。⛔ **禁止卖惨**——哆咪的故事不能当催单工具 |
| **走为上**（第三十六计）  | 该退就退           | ⭐ **她说了不 → 收场关门**。⛔ 不许留"我随时都在"                      |
| **无中生有**        | 编故事            | ⛔ **绝对禁止**。编城市、编展览、编奖项、编客户案例——全是地雷                  |
| **美人计**         | 用暧昧换成交         | ⛔ **红线中的红线**。人设是朋友，不谈感情、不暗示、不越界                     |
| **趁火打劫**        | 消费他的伤痛         | ⛔ **绝对禁止**。宠物过世不是成交契机                               |

## 三、《穷爸爸富爸爸》→ 三条

### 1. 客户是**资产**，不是一次性交易

> 资产是把钱放进你口袋的东西；负债是把钱拿走的。

- 他不买，也**不要冷淡**——那是真朋友和假朋友的分界线。
- **很多单子是在 Day 7 之后几周才来的**，而且他会介绍别人。
- 📌 推论：**Day 8+ 的长期维系不是"没成交后的安慰奖"，它是正经的资产运营。**

### 2. 「我买不起」→「我怎样才能买得起」

> 穷爸爸说"我买不起"，富爸爸**禁止说这句话**，改问"我怎样才能买得起"。

**这是客户说"贵"时的唯一正确反应**。

- ❌ 不要降价（降价＝承认之前报高了）
- ❌ 不要说"那算了"
- ✅ **重构问题**：「是总价的问题，还是现在这个时间点的问题？」
  - **是总价** → 换小尺寸（重构标的，不是降价）
  - **是时间点** → 定金分档（$30 素描稿 / $99 占位费 / 50%），**把一次大额变成几次小额**

⭐ 关键：**这两种回答都保住了价格，同时给了他台阶。** 男性客户尤其吃这个（见男性弱点第 7 条）。

### 3. 别用时间换钱，要让时间产生复利

- 一幅画只能卖一次（**定制画无法二次销售**）。
- 但**一段关系可以产生很多次**：他自己的第二幅、他介绍的朋友、他的口碑。
- 📌 推论：**在"让他记住你"上花的时间，回报高于在"说服他买"上花的时间。**

## 四、销售学 → SPIN 与西奥迪尼六原则

### SPIN 四层问题（Neil Rackham）

| 层           | 作用           | 可聊的具体话题                                |
| ----------- | ------------ | -------------------------------------- |
| **S 背景**    | 了解现状         | 「它叫什么名字？」「你们一起多久了？」                    |
| **P 难点**    | 发现痛点         | 「手机里有没有一张你真正满意的照片？我猜大部分都糊了。」           |
| **I 暗示**    | 放大后果         | ⚠️ 「照片会丢，手机会换——到最后你手上还剩什么？」**极强，但极危险** |
| **N 需求-效益** | **让他自己说出价值** | 「如果每天出门前都能看见它，会是什么感觉？」                 |

⭐ **N 类是最值钱的**：让他自己说出价值，比我们说一百句都强。  
⚠️ **I 类要慎用到几乎不用**：它踩在"消费伤痛"的红线边上。真要用，必须是他先讲到这个方向，  
而且**语气要是感慨，不是吓唬**。

### 西奥迪尼六大原则

| 原则       | 怎么用                   | 对应话题                                |
| -------- | --------------------- | ----------------------------------- |
| **互惠**   | 先给，他就欠一点（本能，不是道德）     | 零风险礼物：存图、短视频、勾小构图                   |
| **承诺一致** | 小承诺会导向大承诺             | ⭐ **让他纠正你**——他一纠正，就投入了              |
| **社会认同** | 别人也这么做                | 「之前帮人画过一只……」（⚠️ **必须是真实案例，一个都不许编**） |
| **喜好**   | 相似的人更容易被说服            | 共同点：都做饭、都养猫、都去过某个地方                 |
| **权威**   | 专业背书                  | 师父、师姐画舍、去过美国看展、得奖（⚠️ 自夸要自己先消解）      |
| **稀缺**   | ⛔ **禁止制造**（"限时/今天下单"） | ✅ 但**真实的稀缺可以说**：工期长、我的时间有限、定制画无法复制  |

## 五、男性弱点（美国中年男性客户）

| 弱点                   | 能聊什么                        | ⛔ 不能做什么                     |
| -------------------- | --------------------------- | --------------------------- |
| **1. 想被认可，尤其在专业领域**  | 请教他的专业，让他评价你的构图（收敛型选项）      | 不要在他专业领域装懂                  |
| **2. 不善表达情感，但渴望被理解** | 给他**具体的事**讲（"它几点催你吃饭"），别问感受 | 不要问"你是什么感觉"——他答不上来就会沉默      |
| **3. 喜欢解决问题、当专家**    | 给他一个具体问题让他帮你解决（时差、某个英文说法）   | 不要给他一个情绪让他接                 |
| **4. 极度抵触被推销**       | 全程不提钱，让他自己走到那一步             | 一旦他闻到推销味，门就关了               |
| **5. 决策慢，但一旦信任极忠诚**  | **慢就是正常的，别催**               | 不要用"限时"逼他——逼出来的决定他会反悔       |
| **6. 对陌生女性主动示好有警觉**  | 靠作品、过程、声音证真                 | ⛔ **自拍红线**（Day 2–3 之前绝对不发）  |
| **7. 自尊心强，不愿承认买不起**  | 给台阶：小尺寸 / 定金分档（**保住价格**）    | ⛔ **绝不当面降价**——那等于说"其实不值这个钱" |
| **8. 视觉驱动**          | 照片、短视频、构图草图                 | 纯文字长段落他会跳过                  |

⚠️ 第 2 条特别重要：**很多"他不说"，其实是"你问了他答不上来"。**  
把"你是什么感觉"换成"它几点催你吃饭"，他就有的说了。

## 七、⛔ 反面清单（这些框架里有毒的部分，一律不用）

1. **美人计** —— 红线。不谈感情、不暗示、不越界。
2. **无中生有** —— 编城市、编展览、编奖项、编客户案例。**编的东西总有一天对不上。**
3. **制造稀缺** —— "限时优惠""今天下单送相框"一律禁止。**真实的稀缺（工期）才可以说。**
4. **趁火打劫** —— 宠物过世、生病、离别，**不是成交契机**。
5. **苦肉计滥用** —— 自嘲可以，卖惨不行。哆咪的故事**一句话带过**，不展开。
6. **I 类暗示问题** —— "它总有不在的一天"这类话，⚠️ 几乎不用。用了就是踩红线。
