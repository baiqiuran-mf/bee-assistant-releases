## 1. 沟通技巧

**非暴力沟通 NVC（马歇尔·卢森堡）** —— 四要素 OFNR：
- **观察(Observe)**：说事实不加评判。例：「这周你有 3 天在 10 点后到」≠「你总是迟到」。
- **感受(Feel)**：表达情绪而非想法。例：「我感到焦虑」≠「你让我很烦」。
- **需要(Need)**：说出底层需求。例：「我需要节奏可预期」。
- **请求(Request)**：具体可执行，非命令。例：「明天能 9 点前到吗？」而非「你别迟到了」。

**关键对话（科里·帕特森）** —— STATE 工具包：
- **S**hare 分享事实（最不易争议的部分）
- **T**ell 说出你的结论 / 故事
- **A**sk 询问对方观点
- **T**alk 试探性表述（「我有点疑惑，会不会是…」）
- **E**ncourage 鼓励对方说出真话
- 安全两大支柱：**共同目的** + **互相尊重**；一旦对方沉默/暴力，用「对比说明」+「重建目的」把安全感拉回。

**通用心法**：先处理情绪，再处理事情；对事不对人；把「你」开头的指责换成「我」开头的表达。

## 2. 异性 / 女性沟通

- **底层**：真诚 > 技巧；尊重边界；先倾听理解，再表达观点。
- **先接情绪再讲理**：对方情绪激动时，不急着给方案、不急着辩对错，先确认感受（「你听起来有点委屈」）。
- **用「我感受」句式替代指责**：「我觉得被忽略」优于「你总不理我」。
- **三不**：不评判、不试图「赢」、不替对方做决定。
- **分寸**：关系未到不越界打探隐私；不物化、不拿她和别人比较。
- **雷区**：说教式回应（「你应该…」）、否定感受（「这有什么好生气的」）、把安慰变成解决方案。
- **适用**：朋友式沟通、亲密关系、避免「说教男」印象。

## 3. 鬼谷子（纵横家）

核心：揣摩人心、因势利导、纵横捭阖。十二篇要点：
- **捭阖**：开合之道。或开而示之、或闭而藏之，掌握对话主动权。
- **反应**：反覆试探，以静制动，投石问路听其辞。
- **内揵**：内通情感、外结谋略，使上下相得、言听计从。
- **抵巇(xī)**：察缝隙（危机/矛盾苗头），可抵塞修补，或顺势取之。
- **飞箝**：先褒扬（飞）以探虚实，再控驭（箝）以收服人心。
- **忤合**：反合之道，可进可退；合于彼则离于此，择明主而从。
- **揣**：量权揣情，摸透对方实力与心理底牌。
- **摩**：顺毛暗推，使对方在不知不觉中自露意图。
- **权 / 谋 / 决 / 符言**：权衡轻重、谋划方略、当机立断、上位者守言纳谏之术。
- **适用**：谈判、识人、说服、危机预判。本质是「心理洞察 + 顺势而为」，非阴谋。

## 4. 三十六计

六套，每套 6 计（按强弱态势分）：
- **胜战计（己强）**：瞒天过海、围魏救赵、借刀杀人、以逸待劳、趁火打劫、声东击西
- **敌战计（对峙）**：无中生有、暗度陈仓、隔岸观火、笑里藏刀、李代桃僵、顺手牵羊
- **攻战计（进攻）**：打草惊蛇、借尸还魂、调虎离山、欲擒故纵、抛砖引玉、擒贼擒王
- **混战计（乱中）**：釜底抽薪、混水摸鱼、金蝉脱壳、关门捉贼、远交近攻、假道伐虢
- **并战计（友军）**：偷梁换柱、指桑骂槐、假痴不癫、上屋抽梯、树上开花、反客为主
- **败战计（劣势）**：美人计、空城计、反间计、苦肉计、连环计、走为上
- **核心思想**：虚实、奇正、因敌制胜；重点在「势」的运用与时机，而非诡诈本身。

## 5. 商业学

- **波特五力**：供应商议价力 / 买方议价力 / 新进入者威胁 / 替代品威胁 / 行业内竞争强度。
- **价值链**：基本活动（进—产—储—销—服）+ 支持活动（基建/HR/技术/采购），看哪环创造最多价值。
- **蓝海战略**：价值创新，甩开「血拼红海」，开创无直接竞争的新需求。
- **SWOT**：优势 S / 劣势 W / 机会 O / 威胁 T。
- **PESTEL**：政治/经济/社会/技术/环境/法律 宏观扫描。
- **平衡计分卡**：财务 / 客户 / 内部流程 / 学习成长 四维度评价企业。
- **适用**：分析一个生意或行业、给战略拍板提供依据。

## 6. 管理学

- **泰勒科学管理**：标准化作业、工时研究、差别计件工资（效率起点）。
- **法约尔 14 条**：分工 / 权责 / 纪律 / 统一指挥 / 统一领导 / 个人利益服从整体 / 报酬 / 集权 / 等级链 / 秩序 / 公平 / 人员稳定 / 首创精神 / 团结。
- **梅奥霍桑实验**：人不是纯「经济人」，社会与心理因素显著影响效率（人本管理起点）。
- **德鲁克目标管理 MBO**：目标自上而下分解，员工自我控制而非被盯。
- **戴明 PDCA**：计划 Plan—执行 Do—检查 Check—处理 Act，循环持续改进。
- **圣吉学习型组织**：自我超越 / 改善心智模式 / 共同愿景 / 团队学习 / 系统思考。
- **适用**：带团队、定流程、推动改进。

## 7. 人情世故（中国式处世）

- **礼尚往来**：有来有往，人情要记、要及时还。
- **分寸感**：话不说满、事不做绝；知进退、留余地。
- **外圆内方**：表面融通客气，底线原则守住不让。
- **看破不说破**：给人留台阶、不当场拆台。
- **知世故而不世故**：懂规则、不沦陷；保持本心。
- **雪中送炭 > 锦上添花**：困顿时的帮助最被人记。
- **适用**：职场、长辈、客户关系里的「度」与分寸。

## 8. 营销学

- **科特勒 STP**：细分 Segmentation → 目标 Targeting → 定位 Positioning。
- **4P**：产品 Product / 价格 Price / 渠道 Place / 促销 Promotion。
- **4C**（用户视角）：顾客 Customer / 成本 Cost / 便利 Convenience / 沟通 Communication。
- **4R**（关系营销）：关联 Relevance / 反应 Reaction / 关系 Relationship / 回报 Reward。
- **7P**（服务业）：4P + 人 People / 过程 Process / 有形展示 Physical Evidence。
- **定位（特劳特/里斯）**：在顾客心智中占据一个「第一」的位置。
- **适用**：怎么让对的人知道你、记住你、最终买你。

## 9. 销售学

**SPIN 提问法（尼尔·雷克汉姆）** —— 用提问让客户自己说出需求：
- **S 背景(Situation)**：了解现状（少问、别惹烦）。
- **P 难点(Problem)**：挖痛点（「现在最卡的是哪一步？」）。
- **I 暗示(Implication)**：放大后果（「这卡点拖下去会损失什么？」）。
- **N 需求-效益(Need-payoff)**：让客户自己讲价值（「如果这问题解决了，对你意味着？」）。

**西奥迪尼影响力六原则**：
1. 互惠（先给小恩惠）
2. 承诺一致（让人先小承诺）
3. 社会认同（别人都这么做）
4. 喜好（像你/夸你/跟你聊得来）
5. 权威（专家/资质/头衔）
6. 稀缺（限时/限量/独有）
- **第七原则（先发影响力）**：统一性 / 归属感（让人先认同「我们是一类人」）。
- **适用**：高客单、B2B、引导客户主动想买。

## 10. 心理学

- **卡尼曼双系统**：系统 1（直觉、快、省能）/ 系统 2（理性、慢、费神）。
- **启发式偏差**：锚定效应 / 可得性偏差 / 代表性偏差。
- **前景理论**：损失厌恶（损失的痛感 ≈ 获利的 2 倍）；决策依赖「参照点」。
- **峰终定律**：一段体验的记忆，由「峰值」+「结尾」决定，过程长短影响小。
- **其他**：认知失调、确认偏误、从众效应。
- **适用**：理解客户为何这样买、设计说服路径、也警惕自己被操纵。

## 11. 人性的弱点（卡耐基）

- **三不**：不批评、不指责、不抱怨（批评只会引发防御与怨恨）。
- **真诚地赞赏**：给人「重要感」是最强驱动力之一。
- **激发对方内在渴望**：多谈「对方想要的」，少谈「你想要对方做的」。
- **让人喜欢的 6 方式**：真诚关心 / 常微笑 / 记住对方名字 / 做个好听众 / 谈对方兴趣 / 让对方感到自己重要。
- **说服 12 条（节选）**：避免争论、尊重对方意见、有错就认、从「是的」开始、让对方多说、让对方觉得主意是他想的。
- **改变人而不伤感情的 9 条（节选）**：先赞美再指正、间接提醒、给人美誉去维护、鼓励、让错误看起来容易改。
- **适用**：广结人缘、减少对抗、化解冲突。

## 12. 富爸爸穷爸爸（清崎）

- **资产 vs 负债**：资产 = 往你口袋装钱的东西；负债 = 从你口袋掏钱的东西。
- **现金流象限 ESBI**：雇员 E / 自雇 S / 企业主 B / 投资人 I。
- **B-I 三角形**：使命—团队—领导力—现金流管理—沟通—系统—法律—产品，八块搭稳才成「企业」。
- **老鼠赛跑**：为钱工作的死循环；财务自由 = 被动收入 > 总支出。
- **财商四技能**：会计 / 投资 / 市场 / 法律。
- **适用**：个人理财启蒙、设计「让系统替你赚钱」的生意。

## 13. 贫穷的本质（班纳吉 / 迪弗洛）

- **RCT 随机对照试验**：用科学对照替代「我觉得穷人怎样」的猜想。
- **贫困陷阱**：今天太穷 → 无力投资明天（教育/健康/本钱）→ 明天更穷，闭环难破。
- **三个 I**：Ideology 意识形态（固有观念）/ Ignorance 无知（信息差）/ Inertia 惯性（改不了的习惯）。
- **心智带宽**：贫穷持续占用认知资源 → 人更容易短视、冲动决策。
- **即时满足偏好**：在「今天的一块糖」与「明天的两块糖」之间，贫困环境让人更难等。
- **适用**：理解「为什么好心的救助会失灵」；也用来警惕自身的决策陷阱。

## 14. 千门108局（江湖谋略体系）

- **结构**：36 天局（明面阳谋）+ 72 地局（暗面布局），合称 108 局。
- **上八将（常见框架）**：正 / 提 / 反 / 脱 / 风 / 火 / 除 / 谣 —— 八种「做局/破局」的手法归类。
- **下八将**：对应局法的应对之策（各流派名目略有出入，不必死记具体字诀）。
- **经典局例**：开门揖盗、金蝉脱壳、李代桃僵、借刀杀人、浑水摸鱼等（多与三十六计相通）。
- **核心用途**：**识局、破局、防骗**，看透别人给你布的「局」，而不是教人使坏。
- **注意**：属民间/江湖谋略体系，来源驳杂、真伪参半，宜作「思维训练 + 防骗识局」之用，不可当作实操指南；勿用于损害他人。
