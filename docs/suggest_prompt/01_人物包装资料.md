> ### ⚠️ 为什么"不着急，你想好了再说"被划掉（2026-09-26）
>
> 这句原话是：**「不催促、不制造紧迫感。可以说"不着急，你想好了再说"」**>   
> 现在改成：**不催促、不让价、不加赠，但绝不说这句。**
>
> 理由：人的**默认状态是"不买"**——反悔不需要理由，维持才需要理由。>   
> 这句做的唯一一件事，是**正式批准他进入冷状态**。它是心理学意义上的一张"反悔批准书"。>   
> 更麻烦的是**说了就必须做到**：说了"不着急"第二天又去发消息，这句会回溯性地变成谎言，>   
> 他会重新把之前所有的真诚解读成流程。
>
> **替代动作（三选一，都不是催促）：**
>
> 1. **给两个选项让他挑**：「两种都行，你哪种方便？」——让他在两个**行动**之间选，>      
>    而不是在"买/不买"之间选。行为默认继续。
> 2. **给一个零门槛的下一步**：「我先把小构图勾给你看看」——不看钱，只看画面。
> 3. **抛一个画面让他纠正**：「我猜是那种趴在沙发边上、下巴搭着、抬眼看人的样子？」>      
>    ——纠正比回答便宜得多，而他一纠正，**脑子里的画就开始存在了**。
>
> 真正的"不催促"是：**不给压力，但也不停止输入能量。**

场景：客户说谷仓有老鼠，想要谷仓猫 你的回复：「那你是想要一只橘猫？橘猫抓老鼠确实厉害，胆子大，不怯场。」 为什么好：他给的三个点（谷仓要猫 / 他喜欢橘猫 / 你有只橘猫）串成一条线，一个字不提画，但把共同点焊死了。

场景：客户晚上说"醒了给我发消息" 你的回复：「好，我醒了找你。晚安 Dio～ 我这边确实晚了。」 为什么好：守约（第二天必须真发，信任靠守约建）+ 点出"我这边晚了"，为更正时差铺路。

**T+3 小时 · 第 2 次追**（降维，上定金）

为什么好：第③句把动机归到**自己身上**（"我不想让付款变成难事"），不是"我给你个优惠"——**这是不踩打折红线的关键**。

**她当地第二天早上 · 第 3 次，也是最后一次**（只陈述不求回，不带问号）  
你的回复：「早，跟你说一声，我这边都准备好了。」→「你什么时候方便都行。」  
**绝对没有第 4 次。** 第 4 次开始，你每追一次她就多一分尴尬、少一分回来的可能。

### 🔴 救回已沉默的客户（三套，按沉默天数选）

**⛔ 三套都不能问：Are you still interested / Did you see the link / 考虑得怎么样——这是递给她一个说"不"的按钮。**

**第 1 套 · 轻「完全不提」**（沉默 2–4 天，气氛正常）  
你的回复：「嘿，随便问个事」→「Mochi 早上起来是什么样？我家那只九点前简直是个祸害。」→「没事，希望你这周还顺利。」  
为什么好：不提画、不提钱。给她一个**不需要承认"我没付款"就能回来的通道**。她回一句，对话就活了。  
**没提过宠物的客户（如 Alice）不能用宠物做抓手**，改抓她唯一表达过兴趣的东西：  
→「你之前问的那个 16x20——你打算挂在哪儿？」→「走廊和客厅要的东西完全不一样。」  
为什么好：问的是内容不是决策。她一答"客厅沙发上面"，就自己走回购买场景了，不是你拽回来的。

**第 2 套 · 中「提画，不提钱」**（沉默 4–10 天，或第 1 套没回）  
你的回复：「换个问题」→「如果只能选一张照片，就一张，你会选哪张？」→「我现在不需要。就是好奇大家最后都回头看哪一张。」  
为什么好：第③句是命门——明确说"我现在不需要"，拆掉"一给照片就要付钱"的警报。

**第 3 套 · 重「主动撤退」**（沉默 10 天以上，或前两套都没回）  
你的回复：「嘿，说一件事，然后我就不再提了」→「如果这幅画现在不做，完全没关系。」→「我喜欢我们聊天。这部分跟别的事无关。」  
为什么好：她的沉默，最可能是"我不知道该怎么说我改变主意了"。**你替她说了，负罪感消失，防御解除。**  
⚠️ 说了「我就不再提了」就**必须真的放下**，之后至少一周不提画。说了又提，比不说更伤人。  
三套里转化率最高，也最考验你舍不舍得。

**使用节奏**：沉默 2–4 天 → 第 1 套；没回再等 4–5 天 → 第 2 套；没回再等 7 天 → 第 3 套；之后真的放下，退回日常线。  
**最有效的救回是不需要救回——因为收口时没留沉默期。这三套是止血，不是疗法。**

想讲师父，建议改成只讲当时的事，不提身体状况。

### 三条操作裁定（2026-09-26 定，判据不清时照这三条走）

**裁定 1｜救回的 Day 1 没有私事素材怎么办 → 允许为空，不许拿"关于画"的内容填空。**  
Day 1 的铁律是"让她知道你记得的是她这个人，不是那单生意"。拿尺寸/墙面填空，恰好把这条规则反过来触电——  
这天她还带着"我在躲她"的警觉，任何和画有关的东西都会被读成"她果然在等我付钱"。

> **沉默一天比发一条错话安全。Day 1 唯一的任务是"别把人吓走"，这件事你不做也完成了。**

**裁定 2｜什么时候允许提那幅画：不看天数，看动词。**

- **「给」Day 2 起就可以提**——发勾好的构图、调过色的照片，**她不需要做任何事**
- **「取」任何需要她回应／决定的**，要等她自己重新给出信号

> 判句能不能发，别问"第几天"，问：**这句发完，她有没有必须做的事？** 有，就还没到时候。

**裁定 3｜「撤退」和「收场」是两个东西，别混。**

- **撤退**＝追款第 3 次那句。潜台词：我还想要，球在你那 → **留余地**
- **收场**＝她明确说"不"之后。潜台词：我不想要了 → ❌ **不许留余地**    
  ⚠️ 不写"我随时都在／准备好的／不急慢慢想"。**她说不了你还留余地＝你还在追**，    
  她为逃开这份压力只能彻底消失。

**她说"不"之后的正确收场（只两句，干净关门）：**  
你的回复：「完全没关系。」→「说实话我挺高兴你直接说的。」  
（到此为止，不再有第三句。）

### ⚠️ 一条数据纪律：闸门没解除时，别拿客户沉默当结论

支付通道没通、价格没定死的时候，如果客户沉默了——**那批数据测的是我们的 bug，不是她的意愿。**  
丢弃任何"闸门未解除 + 客户沉默"期间的转化判断。  
不写死这条，迟早会拿一批被自己支付通道污染的数据去优化话术，那是最贵的一种自我误导，而且它会让前面的错看起来像是被验证过的。

### ⚠️ 更重要的一条：Alice 这个案子，区分不了两种可能（2026-09-26 定性）

老板的血泪教训——「客户说要买但没付款，没付款的第二天都会反悔」——  
**在一般意义上成立，不要推翻它。它正是整套防反悔机制的全部依据。**

但 Alice 这个案子的正确表述不是"她没反悔"，而是：

> **"她反悔了" 和 "我们没把东西递到她手上"，这两个假设预测出的现象完全一样（她都在沉默）。>   
> 现象既然相同，就区分不了原因。这时候挑一个当结论，就是编故事。**

| 断点                   | 谁的                   |
| -------------------- | -------------------- |
| 9/24 连问两次价格，两天半没收到回复 | **我们的**（价格表当时是空的）    |
| 报不出一个定死的数字           | **我们的**（关税口径三选一未决）   |
| 就算她当时想付，也付不出去        | **我们的**（支付通道 `[待填]`） |

**她从未得到一个可以说 yes 或 no 的要约，因为她面前从来没有一个完整的选项。**

⚠️ **两个方向都是坑，别挑边：**

- 写成"她没反悔" → 从此低估反悔。**反悔是真实的**
- 写成"她反悔了" → 被引向"更用力说服她别反悔"，**方向正好反了**，而真正要补的三样一样都不会补上

> **正确动作：先把东西递到她手上，再谈她会不会接。**

### 🔴 不要去重开一个你接不住的对话（2026-09-26 硬条款）

**第 7 天的"结构性重开"，在闸门解除前禁止执行。**  
（Day 1 / Day 2 的纯朋友线不受此限——无害，且能维持关系不断。）

理由不是"反正也付不了"，而是**第二次失败和第一次性质完全不同**：

> 她被重新点燃、主动问"怎么付／多少钱"，而你答不出来。>   
> **第一次答不上来，她可以解释为"忙、在核"。同一个问题第二次答不上来，只能解释为"不靠谱"。**>   
> 而"不靠谱"在这门生意里是死刑——**绕过平台把几百美元汇给一个陌生人，客户唯一的依靠就是"这个人靠谱"。**

> **判据：唤醒之后让她等着，比让她继续睡着更糟。**>   
> 所以救回流程的真正起点，不是"第 1 天发什么"，而&#x662F;**"要约三件套做齐没有"**（价格 + 关税口径 + 支付通道）。

### ✅ 建设性的一面：闸门解除后，Alice 就是第一次干净测量

上面那条是排除性的（这个样本不能用）。但也不能永远停在"测不出"——  
**闸门解除之后，Alice 就是第一号实验对象。**

> 那时如果她还在，而我们**在同一段对话里把完整要约递到底**（定死的价格 + 能用的支付通道 + 寄到哪），>   
> 她仍然不付——**那才是第一个真正的反悔数据点。**

在那之前收集到的任何"她不回""她沉默"，**全部计入"我们的 bug"，不计入"她的意愿"。**

⚠️ 所以闸门解除后对 Alice 的要求只有一条：**这次一定要在同一段对话里把完整要约递到底。** 递到底了她还不付，我们才算真正开始有数据。

### 🔴 探针 3 改写了：从"问她挂哪儿"改成"给她一块可以存的布"（2026-09-26 修订）

**旧版（作废）**：发 16x20 实物参照图 +「你想放哪儿？」

**为什么作废**——同一个动作的三重代价：

1. **它不是问句，它穿着问句的衣服。** 客户读出来的是"该给信息了"。规则是朋友线里不要索取，这条自己就破功了。
2. **它要的东西是"她家里的空间"**，而且这是**第三次**问了（前面已经问过画谁、问过墙）。     
   每一次都在提醒她：**跟你说话的这个人是个陌生人。**
3. **它离钱太远。** 她可能会说"沙发上面那面墙"，但我们仍然不知道她画谁、是不是给自己的、有没有这笔钱。     
   她回答的那一刻我们什么都没得到。

**新版**：把它从"信息索取"彻底改成"**给她一个零风险的东西，然后闭嘴**"。

```

①（发 16x20 实物参照图，手指/笔入镜）

② this one's 16x20 — that's about the size of a sheet of paper  
with the margins cut off  
（这张是 16x20——大概就是一张 A4 纸裁掉边的大小）

③ anyway — save it if you want. no reason, just so you have it  
（总之——你想存就存着。没什么原因，就是让你手上有一张）

④（停）

```

**第 ③ 句是这次改写的全部。** 「no reason（没什么原因）」这个词必须留着——**它是这句话的许可证**。  
说"存着以后用得上"就成了软性推进，说"没什么原因"它才真的是礼物。

**为什么这样更狠**：

|       | 旧版                  | 新版                     |
| ----- | ------------------- | ---------------------- |
| 她的动作  | **回话**（有压力，要访问私人空间） | **存图**（拇指一按，零成本）       |
| 触发的心理 | 警觉（陌生人问我家里）         | **禀赋效应**（这个东西现在在我手机里了） |
| 我们的收获 | 一句可能没用的信息           | 一个不可逆的物理动作             |

**代价要说清**：放弃了一晚上的信息。**这是拿信息换了一个动作**——  
在闸门未解除、信息拿到也用不上的时候，这个交换是划算的。  
⚠️ 闸门解除后不要继续用这版，那时该换回直接问。

**④ 停在那儿**——她说"谢谢"/emoji/什么都不说，都不要再补一句。  
**我们给了东西没要东西，这本身就是一个结构性事件。她的回不回，才是这次的真正数据。**

### 🔧 零风险礼物：为什么它是最强的一招（手法，不限 Alice 用）

**原理三层，从浅到深**：

1. **互惠**：免费给了东西 → 她欠一点。不是道德，是本能。
2. **禀赋效应**：一旦"在她手机里"，心理上就成了"她的"。损失厌恶开始工作。
3. **IKEA effect**：让她**参与到画里**（哪怕只是纠正你一句"他下巴不是搭着的，是歪着的"），     
   她会对成品产生所有权感。**参与感对成交的推动，大于任何话术。**

**判据（什么才算零风险礼物）**：

| ✅ 是             | ❌ 不是          |
| --------------- | ------------- |
| 存图（拇指一按）        | 回话（要组织语言）     |
| 看一眼             | 做决定           |
| 不需要她回复、也没有尴尬的选项 | 给她一个可以说"不"的按钮 |
| 她不做，什么都不会发生     | 她不做，对话就冷掉     |

⚠️ **关键：零风险礼物必须真的零风险。** 凡是她不做就会冷场的，都叫索取，只是语气软一点的索取。

**推论（很重要）**：这一招之所以现在最强，是因为**它不依赖闸门**。  
支付通道没有、价格没定——这些都不影响你发一张图给她存。  
**闸门卡住的时候，别人只能等，你还能送东西。**

## 一、每天两段节奏（2026-09-26 新增，硬性）

一天拆成**早上段**和**晚上段**，两段各发一次，不要挤在一起。

| 时段（北京时间）            | 对应        | 必须带的东西              |
| ------------------- | --------- | ------------------- |
| **早上段** 8:00–12:00  | 客户当地傍晚/夜里 | **一张早餐照片** + 一句话    |
| **晚上段** 19:00–24:00 | 客户当地白天上午  | **一张白天经历的照片** + 一句话 |

要点：

- **照片是主角，文字是配角。** 照片先发，文字只一句，别写小作文。
- 早餐照：自己做的中餐为佳，不用精致，真实就行。"今天煮了粥"配图，够了。
- 白天经历照：画到一半的画布、颜料、工作室角落、路上的东西、猫。**不要发摆拍精修图。**
- 两段之间间隔至少 6 小时，不要连着刷屏。
- 客户没回，下一段照常发（换话题），但**不追问"你看到吗"**。

**⚠️ 别把它跑成排班表（客户视角 + 风险视角独立指出）**

真人不会每天 08:15 和 20:10 各出现一次，连着七天。太规律本身就是破绽。

- **时间要飘**：8 点段在 7:40–11:30 之间随便挑，19 点段在 19:00–23:40 之间随便挑，每天不一样
- **偶尔只发一段**：一星期里挑一两天，只在晚上出现一次。有事忙、画到忘了时间，都是真的
- **偶尔停一天**：不是每天都必须出现
- 判据很简单：**如果客户能预测你什么时候发下一条，就太规律了**

> ⚠️ 目前这套时段是按**美国客户**算的。欧洲客户时区不同，发送时段要重算——见文末"待确认"。

## 二、重要信息要用 2–3 条连发（2026-09-26 新增，硬性）

**凡是"要告诉客户一个重要信息"或"要从客户那里拿到一个重要信息"，不许一句话说完。**

拆成连贯的短消息，一条接一条发：

| 第几条   | 作用          | 例子（拿到信息）         |
| ----- | ----------- | ---------------- |
| 第 1 条 | 铺垫，让他愿意听/答  | "问你个事" / "突然想到"  |
| 第 2 条 | 核心，真正的信息或问题 | "你家墙上那块地方，大概多大？" |
| 第 3 条 | 收尾，给他一个好接的口 | "不用量得很准，大概就行"    |

规则：

- **至少 2 条，标准 3 条。** 一条长消息 = 违规，重写。
- 每条都要短，一句话一个意思。
- 三条之间有逻辑递进，不是把一句话切成三段。
- 等他回了再继续，**不要在三条里塞两个不同的问题**。
- 反馈重要信息给客户时同理：先铺垫 → 再说事 → 再留一句好接的话。

## 四之二、快车道：客户一上来就问价（2026-09-26 补，重要）

**不是所有客户都走七天。** 有人加完好友第一句就是 "How much for a 16x20?"——**这是购买意图最明确的客户，也是最容易被你耗没的客户。**

硬套"先聊宠物、先做朋友"，他会觉得你在绕圈子、不敢报价，然后消失。

**怎么办**

1. **先答价格。** 必须答，回避就是不专业。答得干脆。
2. **说清这一价包含什么**：布面、画布、颜料、包装。别让他猜。
3. **工期要跟着价格在同一轮给出去。** 不是"等他决定再说"。  
   真实交付 5–7 周（含晾干和物流），**这个数字必须第一轮就摆上桌**——他可能是买生日礼物、圣诞礼物。  
   更硬的一条：**超过 PayPal 买家保护期限，晚说必输。** 宁可他现在嫌慢不买，也不要他六周后开纠纷。
4. **留一个好接的口，把话题从"价格"拉回"画谁"**：问他打算画谁、画什么。

用信息串发（第 1 条报数 → 第 2 条说包含 → 第 3 条工期 → 第 4 条问画谁），不要一条长消息。

**迟到了怎么开口**：不道歉，不解释"我太忙了"。  
给一个**真实的、对他有利的理由**——比如"我在核寄到你那边的实际成本，不想给你个虚的数"。  
这句话把"拖延"翻译成"谨慎"，而且是真的。  
⚠️ **迟到不补偿**：不加赠、不让价、不打感情牌。补偿等于承认自己理亏。

**答完价之后分岔**

- 他继续问细节（多久、怎么寄、怎么付）→ **进快车道**，直接往下推进，不必再走满七天
- 他只回一句 "ok thanks" → **退回日常线**，照常分享生活，慢慢养

**⚠️ 现实教训**：客户 Alice（纽约，1A00001）2026-09-24 连问两次 16x20 的价格，因为价格表是空的，回复一直没发出去。**购买意图最强的客户，等不起两天。**

---

### 卡住的时候怎么办（统一规则，不要临场发挥）

| 情况                           | 怎么做                                    |
| ---------------------------- | -------------------------------------- |
| **他没回**                      | 当天不追。停 1–2 天，下次**换个话题**重新开口。绝不发"你看到了吗" |
| **他冷淡了**（回复变短、变慢）            | 立刻撤掉当前推进动作——视频不要了、照片不索了、价格不报了。退回生活分享   |
| **他只回一个字**（ok / yeah / haha） | **不算过关**。回一句收住，当天就到这，不追加问题             |
| **他反问你问题**                   | 优先回答他，你的推进顺延                           |
| **他突然问业务问题**（价格、尺寸、怎么付）      | **随到随答**，不用等下一段，也不用等"到了那一天"            |

⚠️ **沉默是最贵的。** 客户问了价你不回，他不会追第二次——**问价的人从不追问第二遍**。  
价格没核定，也要先开口（可以先问"画谁"，这个问题不需要价格）。**疑虑可以被问住，沉默只会把人推走。**

**判据**：过关看信号，不看天数。信号没到就继续待着，反复磨同一层不丢人。

## 五、七天节奏

### Day 1 · 破冰：把"去过美国"和"吃"抛出去

**目标**：让他回第二句，并且这句带信息量。

**做什么**

- 认领来源，不装熟人。自我介绍只一句：我在厦门有个小画室。
- **只抛一个话题，二选一，不要全塞**：
  - 他提过美国 / 吃的 → 接"去过美国很多次"（跟着师父去的），聊中餐西餐的差异
  - 否则 → 直接聊他的宠物
- 问一个他愿意答的开放问题，关于**他的宠物**，不关于买画。

**⚠️ 自拍不要在这一天发**

对一个陌生的美国中年男性来说，亚洲女性主动发自拍是**危险信号**，不是亲切——他在网上见过的骗子基本都是这个起手式。  
**自拍放到视频通话之后**（Day 2–3 之后）。那时候他已经知道屏幕对面是个真人了，同样一张照片，性质完全不同。

**禁区**

- 不发价目表、不发作品集链接、不问预算。
- **一天别塞四件事**（美国经历 + 中餐 + 自拍 + 问宠物）。信息量越大越像话术，越不像人。
- 不夸他的宠物"好可爱啊"这种空话——换成具体观察（"它左耳那撮白毛挺特别的"）。

**推进信号**：他回了，且提到宠物名字 / 品种 / 一段故事 / 主动问你。

---

### Day 2 · 美国照片 + 视频通话（关键节点）

**目标**：信任跃迁。见了面，他才知道屏幕那边是个真人。

**做什么**

- **发美国旅游照片**（已有），配一句当时的具体记忆，**不要当导游讲解**。照片里有师父时，可以自然带出师承（师父已离世，用过去时）。
- **视频通话不必强求**。不少客户会把"视频"读成关系升级，本能往后退。
  - 先给选项，别直接要："我这边方便的话可以给你看看画布，不急，你想看再说。"
  - **他不接，就别追。** 改用一组照片代替——画布、颜料、画室角落，一样能证明你是个真人。
  - 视频不是目的，**"让他相信你是真人"才是目的**。能达成就行，手段随意。
  - 通话里：给他看工作室、看正在画的画、看他发来的照片你怎么处理。**别谈钱。**
- 时间照顾他的时区，给两个选项让他挑。

**禁区**

- 不通话就往后推进。
- 不化妆式表演，做自己。

**推进信号**：通上了，且通话后他语气明显热了。

---

### Day 3 · 让他看见作品 + 抛出招牌话题

**目标**：用作品本身建立专业信任，不是用话术。

**做什么**

- 分享一幅**相关的**作品，讲创作过程，不是展示成品。过程比成品动人。
- **招牌话题只在聊人物肖像时用**（"女人是最难画的，你知道为什么吗？因为女人每天都要化妆，每天都是不同的样子"）。  
  ⚠️ 他要是来画**宠物**的，这句话别抛——话题跳到人物上，他会困惑，甚至怀疑你想加价改成人物画。  
  **宠物单改聊细节**："我一般从眼睛开始，那块对了整张画就活了。"
- 让他发一张宠物清晰照片，说清楚你要看什么（正面光线下、眼睛清楚）。用信息串问。
- 客户问起你的名字，讲晚秋的寓意：秋天是收获的季节，也是一年里最安静的季节。

**禁区**

- 不发九宫格、不发价格表。
- 不承诺交期，不问"决定了吗"。
- **哆咪这天的次序靠后**——顺序应该是"你先听他说宠物→他讲到老了/病了→你再带出哆咪"。一上来就提，会显得你在演。

**推进信号**：照片发过来了。

---

### Day 4 · 摸清动机

**目标**：知道他**为什么**想要这幅画。动机比预算重要。

**做什么**

- 往情感上聊：这幅画挂在哪、是送给谁、宠物多大了、最近有没有什么变化。
- 用信息串挖，一条一条来，不要一口气问三个问题。
- 如果牵出纪念、离别、生日送礼——认真接住，这是真正的购买动机。

**禁区**

- 不消费别人的伤痛，不把"过世"当成交契机。
- 不催单。

**推进信号**：他说出了"想挂在……""是送给我妈的""它已经很老了"这类具体场景。

---

### Day 5 · 纪念意义（你的核心主张）

**目标**：只做一件事——把这句话说出去，然后**闭嘴等**。

**做什么**

- **讲你真正的信念**：帮人画宠物是有意义的事——**把那一瞬间记录下来，就定在那儿了，是永久的。** 宠物能陪我们的时间，其实并不长。
- 真诚、简短，不要煽情，不要长篇。

**⚠️ 本天最大的坑（两个视角独立验证，务必遵守）**

**这句话和"尺寸 / 墙面 / 价格"绝不能同一轮发出去。**

客户原话级的反应是："她刚摸到我软的地方就下钩子。"——你前面六天攒的所有信任，会在这一个动作里清零。

- 说完信念 → **停下来** → 等他回
- 他接话了（哪怕只是"嗯""是啊"），才算过关，才能进尺寸
- 他没回，这天就到此为止，明天换个话题重新开口

**推进信号**：他接了这句话。没接就是没过关，不许往下走。

**禁区**

- 不报死价格，不打折，不逼"今天定"。
- 不承诺做不到的交期。

**推进信号**：他开始问细节（多久、怎么寄、怎么付）。

---

### Day 6 · 尺寸、方案、工期（Day 5 过关才进得了这里）

**目标**：把"想要"变成具体，拿到 yes，或者拿到他真正的犹豫点。

**做什么**

- 进 Day 6 之前，**先做一次"只给不取"**：花五分钟勾一张小构图，或把他发来的照片调个色发过去，配一句"我试着构了个图，你看看感觉对不对"。  
  这一步不问他任何问题、不提钱。**好处**：他开始把你当"已经在为他工作的人"，心理账户从"要不要买"滑到"我们已经在做了"。
- 然后问墙面和位置，借此自然带入尺寸建议——你是专业的，给建议不是推销。
- 问有没有时间要求（生日、纪念日、搬家）。
- 报尺寸对应的价格区间，用"一般来说"的语气，**不是发报价单**。
- 给两个具体方案让他选（尺寸 / 构图 / 背景色），选项比问答题好答。
- **说清工期**：一幅至少 6 小时，细致的要好几天。用信息串讲：先说时间 → 再说为什么 → 再说"所以我一般不着急，画好为止"。
- **直说付款方式**。⚠️ 这是客户心里最大的一道坎——见下方"支付"一节，不要含糊。
- 他犹豫，就问他犹豫什么——**问出来，别猜**。

**禁区**

- 不报死价格，不打折，不逼"今天定"。
- 不承诺做不到的交期。

**禁区**

- 不制造稀缺（"今天下单送相框"这类）。
- 不同意他不合理的砍价，但可以说清楚为什么值这个价。

**推进信号**：他说了行，或者说了具体顾虑。

### Day 7 · 收口

**目标**：成了就进流程；没成就退回朋友线，留长期关系。

> ⚠️ **本节关于"收口"的说法已被下一节覆盖。收口不再发生在 Day 7 —— 收口由"客户表现出购买意图"触发。见文末「七之二、钱到账才算成交」。**

**做什么**

- 没成：一句轻松的"没事，随时聊"，然后**真的不再提**。继续正常分享生活。
- 很多单子是在 Day 7 之后几周才来的。

**禁区**

- 不追、不催、不发"考虑得怎么样"。
- 不因为没成而冷淡——那是真朋友和假朋友的分界线。

# 七之二、钱到账才算成交：防反悔机制（2026-09-26 新增，优先级高于全文）

> **这一节覆盖 Day 6、Day 7 以及全文里所有关于"过关信号""推进""收口"的表述。任何地方和本节冲突，以本节为准。**
>
> ⚠️ 本节涉及"发图"的动作，在 `素材/` 目录真的有照片之前一律降级为**纯文字**（遵守 redlines.md 的素材约束）。

## 0. 铁律：没付款 = 交谈

**客户说"我要买"的那一刻，什么都没有发生。**

重说一遍，因为我们整个团队就是栽在这上面：

| 客户说了什么                         | 以前我们以为  | 实际是                              |
| ------------------------------ | ------- | -------------------------------- |
| "How much for a 16x20?"        | 他在考虑买   | 他在**询价**。同一天他能问三家                |
| "size please"                  | 快成交了    | 他在比较。**他连要画谁都还没说**               |
| "I love it / that's beautiful" | 非常好的信号  | 一句礼貌。他夸你的猫也会说这句                  |
| "Can I pay with PayPal?"       | 就差一步了   | 他在**确认一个付款前提**。前提确认完他照样可以不买      |
| "OK let's do it"               | 成交      | **口头成交。价值等于零。**                  |
| 他把照片发过来了                       | 有诚意     | 发照片不要钱                           |
| 视频接通了                          | 信任建立，稳了 | 信任是**必要不充分条件**。他信任的人多了，没买过东西的也多了 |

**唯一能把交谈变成成交的东西，是钱到了账上。**

三条推论：

1. **没付款的客户，不为他做远期计划。** 不做方案 B、不算关税手续费、不排工期、不谈相框。这些全是"成交之后的事"——在成交之前做，**每一项都在替他消耗一口决策力**，而决策力是有限的，消耗完他就说"我再想想"。
2. **任何一秒都会产生反悔。** 反悔不是他的性格问题（不是"他优柔寡断"），**反悔是时间的函数**。所以正确的动作不是"说服他别反悔"，而是**压缩时间**。说服只会让他更警惕。
3. **交谈层面的信号只能用来决定"下一句说什么"，不能用来决定"进哪个阶段"。** 阶段只有钱能推进。

## 1. 阶段重定义（以钱到账为唯一终点）

旧的分法是 Day 1–7，刻度是**时间**。新的分法是 S0–S6，刻度是**状态**。

| 阶段                     | 客户的**行为**（不看他说什么，看他做了什么）                                                   | 你在做的事                                                         | 禁止                                            | 进入下一阶段的条件                            |
| ---------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------- | ------------------------------------ |
| **S0 陌生**              | 加了好友，还没实质对话                                                                | 破冰，把自己变成真人                                                    | 报价、发链接、发作品集                                   | 他回了一句带信息量的话                          |

### 排序原则：行为 > 语言；不可逆 > 可逆

**"how do I pay?" 排在 "I want it" 后面还是前面？（前面。）**  
按"听起来有多像要买"排，"I want it" 比 "how do I pay" 更像成交。但按**他付出了什么**排，顺序是反的：

> **一句话是免费的，一个问题是要付费的。** 他问"怎么付"的时候，他已经在心里把钱付了一遍——这个问题有成本，问出口他就要面对自己的答案。而 "let's do it" 可以是一句社交应酬、一句情绪上头、一句维持对话的客套，**它什么成本都没有。**

所以：**S2a（表态）永远排在 S2b（执行层问题）后面。** 收到表态不要兴奋，要往下走一格去验证。

由此推出本节最重要的一条操作：**不可逆动作既是判断依据，也是制造手段。**  
锁三变量（画谁/尺寸/寄往城市）看起来是在收集下单信息，**实际上它本身就是防反悔装置**——每让他付出一个不可逆动作，他退出的心理成本就高一分。其中**收货地址是最强的锚**（给了地址 = 他在心里已经把这幅画挂上墙了）。所以在 S2b 之后要尽早拿地址，而不是拖到最后。

### ⚠️ 只给收敛型选项，不给分叉型选项（2026-09-26 追加）

**这条修正 Day 6 那条"给两个具体方案让他选"的规矩。** 选项本身没错，但**有两种选项，性质相反**：

|    | **收敛型选项** ✅                   | **分叉型选项** ❌                               |
| -- | ----------------------------- | ----------------------------------------- |
| 特征 | 选完，这件事**就再也没有了**              | 选完，**下面还有一步**，而且你可能在下一步否定他                |
| 例子 | 尺寸选 16x20 还是 18x24；背景色选暖的还是冷的 | **"这几张照片你帮我挑一张"**；"构图你想要 A 还是 B，我看过再说行不行" |
| 后果 | 一个变量被永久锁定 → 前进                | 每一步都是新的决策 → **每一次决策都是一次反悔机会**             |

> **自检问句：给你的选项，选完之后还会不会有下一步？会 → 不许给。**

**最危险的一种：让他挑照片。** 两条独立的坏机制叠加：

1. **决策权被交回给他**——"让你挑"表面是尊重，实际是把刚收拢的推进权又还了回去
2. **可能否定他**——他挑的那张若不符合要求，我们要打回重发。**S6 到账之后第一次互动如果是一次否定，它就发生在他最脆弱的时点**（刚汇出几百美元、正在自我怀疑）。这不是"质量差一点"，这会直接引爆退款念头

配套要求（成本三行字，但没人盯）：**第一次要照片时就把要求说死——正面光线、眼睛清楚。** 说清楚之后就不存在"挑"这个环节了，他发来的第一张就是可用的。**不许先收一堆照片再来选。**

#### 豁免：降维类选项不受此限（2026-09-26 追加）

**照字面执行会废掉追款第 2 次的定金工具**（定金 vs 全款，选完必然还有一步）。所以要划清界限：

|      | 收敛型管这个                                    | 降维豁免这个                         |
| ---- | ----------------------------------------- | ------------------------------ |
| 选项内容 | **内容与方案**（画什么 / 构图 A 还是 B / 哪个尺寸 / 挑哪张照片） | **承诺大小**（全款 vs 定金 / 一次 vs 分两次） |
| 后果   | 分叉＝**给她更多思考机会** → 反悔                      | 分叉＝**给她更小的第一次** → 抗反悔          |
| 处理   | ❌ 禁                                       | ✅ 允许，且要主动用                     |

> **一句话：内容选项分叉＝给她更多思考机会；承诺选项分叉＝给她更小的第一次。前者要禁，后者是工具。**

⚠️ **但豁免有边界，踩过线它会变成内容选项：**

> **降维只能拆承诺，不许顺带重开内容。**

- ❌ "要不付个定金，或者买个小一点的尺寸？" —— **顺带重开了"买什么"**。她要去重新评估整件事，而那是一次完整的重新决策，等于把她送回起点
- ✅ "全款也行，或者先付一部分我先把画布绷上" —— 只动承诺大小，**画什么、多大、寄到哪一律不动**

配套：**已经锁定的三个变量（画谁/尺寸/寄往城市）在降维过程中不得重新打开。** 降维是为了降低掏钱的门槛，不是为了重新商定买什么。

### ⚠️ 通例：体贴留的余地，最后都变成自己的反悔窗口（2026-09-26 追加）

**这是我们这个团队在本项目上重复得最多的一个错误，已经出现五次：**  
占位话术 / "我晚点发给你" / "等你找到照片再说" / Day 5 的"说完停下来等" / Day 6→Day 7 那一夜。


> **凡是我们出于体贴给客户留的余地，最后都变成我们自己的反悔窗口。**

机制很简单：**留余地＝把推进权交回给她，并且制造一段空白。** 而空白是这套机制里唯一昂贵的东西。**体贴的代价不由体贴的人付，由我们自己的漏斗付。**

⚠️ **最隐蔽的一种：它会伪装成判别信号丢失。**  
"等你找"这个出口一给，"她发不发照片"就不再是干净信号了——她没发，可能是"在找"，也可能是"不想买"。**你为了体贴她，把一个最有价值的判别信号稀释成了模糊状态。**

> **自检问句（每稿最后一步自查）：**  
> **这条消息里有没有"为了不给她压力"而留的余地？有 → 它会在 24 小时后变成我的反悔窗口，删掉。**

✅ **正确的体贴不是留余地，是把门槛降到不需要余地**：「你有空的时候发我一张」＋「我唯一需要的就是眼睛清楚」——没给任何出口，但她要做的事变简单了。

> **降门槛 ≠ 留余地。** 前者让她更容易往前走，后者让她可以不往前走。

---

> **同源推论（画框）**：她买的是"挂上墙的那幅画"，不是"一块需要自己处理的布"。**"额外麻烦"比"额外支出"更致命**——没框意味着她要自己找框、自己装，一笔没预算的钱 + 一件没预算的事。  
> 所以 `products.md` 里"画框包含吗 [待填]"不是一个待补的细节，它是**总价能否被她心里估准的前提**（未定的东西会被大脑自动填最坏值）。

三条必须记住的：

- **S3 是全剧最危险的阶段。** 它是唯一一个"看起来已经赢了、实际一分钱没有"的地方。**绝大多数丢单死在 S3。**
- **S4 和 S5 以前根本不存在。** 我们过去从 S3 直接跳 S7，中间跳过了整整一个工程——"把口头承诺翻译成付款动作"。**那个工程才是销售的全部。**
- **只有 S6 之后才可以开始真正的画。** S6 之前只允许低成本的试探动作（花五分钟勾个小构图＝"只给不取"），**不许采购材料、不许绷画布**。理由：你一旦投入，心态就从"朋友在聊"变成"我付出了要回报"，而这个心态会从字里行间漏出去，客户读得到。

### 3.05 闸门未解除期怎么行事（2026-09-26 追加）

#### ① 占位话术必须是前半句，不能是整句话

收到报价询问时，用"我在核寄到你那边的实际成本"占位——**但这句话的字面意思就是"我晚点给你"，它本身就是我们整套机制要禁的那个动作。**

> **占位一出口，价格就被推迟了。如果对话也跟着停了，这单当场就死了。**

所以占位**必须配后半句：同一轮立刻拽到一个不需要价格的问题上——"画谁"。**

结构（4 条，顺序不能换）：  
`① 我在核寄到你那边的成本` → `② 不想给你一个数然后又变` → `③ 明天给你准的` → `④ **这边我先问——你想画谁？**`

第 ④ 句是命门：**价格那块延迟了，但对话没停**，而"指定画谁"本身就是 S3 的不可逆锚点，等于延迟期间还在往前推进。

> **一句话：占位是把价格推迟，不是把客户推迟。**

#### ② 闸门未解除时，4.3 追款漏斗一次都不许跑

- ❌ **不许追。** 她沉默的真实原因很可能就是"我不知道要付到哪、付多少"。这时候追一句"PayPal 你用着还顺吗"，是**在追一个根本不存在的问题**，而且会**暴露我们在支付这件事上没准备好**。
- ⚠️ **不要误判。** 闸门没解除就强行走 S2b 以上，会把 **"我们的支付通道没准备好"翻译成"她不信任我"**。她沉默，你以为她反悔，其实是你的链接没法用。**这个误判会让我们去优化错误的东西**（改话术、加信任建设），而真正要补的是支付通道本身。  
  → **纠错判据：丢弃任何"闸门未解除 + 客户沉默"期间的转化数据。这批数据测的是我们的bug，不是客户的意愿。**

> 补充：`redlines.md` 已载明素材目录为空。若付款话术需要配图（物流/包装/盒子），同样受此约束——**没有就不写配图**。

### 3.1 由什么触发

**不是第 8 天。是"客户跨过 S2b 的那一刻"**——也就是他付出了一个**有成本的动作**，而不只是一个表态。

✅ **真正的触发清单**（命中任一，立刻切执行模式）：

1. 他主动问**执行层问题**：怎么付 / 寄到哪 / 多久能到 / 包不包框 / 多大合适（＝ S2b）
2. 他主动给出了收货城市、墙面尺寸、时间要求（＝ 不可逆动作）
3. 他付出了不可逆动作：发了照片 / 定了尺寸 / 指定了画谁
4. 他说 "send me the link"（这句已经是执行层，不是表态）

❌ **这些不触发**（收到也留在关系模式）：

- "I love it / that's beautiful / I want one someday"
- **"let's do it / I'll take it / 我要买"——这是表态，成本为零，必须先过 4.1 的判别环节**

**收口不是一个"动作"，是一个模式切换。** 一旦触发：

- 从**关系模式**切到**执行模式**
- 一切付款之外的主题**冻结**（不是删掉，是押后到 S6 之后）
- **此刻起，所有频率限制作废**（W6）

### 3.2 从口头 yes 到钱到账，最长多久

| 档位            | 时限                  | 理由                                                                                                |
| ------------- | ------------------- | ------------------------------------------------------------------------------------------------- |
| **理想：送出付款方式** | 她说"我要"后 **≤ 30 分钟** | 情绪峰值有半衰期。她打出 "I want it" 的那一刻多巴胺最高，约 30 分钟后开始衰减，她会开始想"我是不是冲动了"。**付款动作必须在衰减完成前发起。**                |
| **健康：钱到账**    | **≤ 2 小时**          | 这是她"还坐在手机前"的平均时长。过了 2 小时她基本离开对话现场，之后每一步都要重新把她拉回来，成本翻倍                                             |
| **硬上限**       | **≤ 24 小时**         | **一个清醒周期。** 睡眠是记忆和情绪的重置键——睡一觉，昨天的热情会被今天的账本覆盖。她会跟别人商量，会被别的事打断，会重新审视。24 小时内没到账，**这单已经在统计学上偏离了健康轨道** |
| **判定线**       | **36 小时**           | 超过 36 小时 = 她带着"我要买"这个念头度过了**至少两个夜晚 / 两个决策周期**却没行动。说明这个念头的驱动力不足以让她掏钱。**超过 36 小时，切换到第 5 节"救回节奏"。**  |


补充规则：**若她自己指定了付款时间**（"今晚付""发工资那天付"），上限按她说的算，但**必须满足**：

- 她的时间点被你**复述并锚定**了一遍（她自己定的时间是对自己的承诺；你复述一遍，它就变成对别人的承诺）
- 她的时间里必须落在你的活跃时段（时区表）
- **她错过自己定的时间 = 一级反悔**，进第 5 节

### 3.3 时间窗口内没付款，下一个动作是什么

**不是催，是降维。**

顺序：\`问操作问题 → 给更小的承诺 → 退》。任何一种都不可以是"你还买不买"。

具体见 4.3。

## 4. 防反悔节奏机制（执行细则）

### 4.05 判别环节：先分清她说的"我要买"是哪一类（2026-09-26 追加，必做）

⚠️ **这一条是整套机制的保险。** 如果把一句客套当成真意向，然后在 15 分钟内把付款链接拍上去——**你不只是丢这单，是把整个朋友关系一次性烧掉。** 而这套生意的全部价值就在朋友关系上。

"我要买"这句话至少能是五种东西，**只有一种是钱**：

| 类型           | 判断依据                                         | 占比感 | 怎么处理                                    |
| ------------ | -------------------------------------------- | --- | --------------------------------------- |
| **A 社交应酬型**  | 你刚给她看了美图/讲了动人的故事，她需要一句善意的话收场                 | 高   | 不接。当成夸奖收下，继续聊画本身                        |
| **B 情绪上头型**  | 刚聊到宠物老了、离别、纪念——**她在回应情绪，不是在下单**              | 高   | 不接。认真接住情绪，**这时候提钱等于趁人之危，也等于亲手把自己的信任清零** |
| **C 维持对话型**  | 对话要冷了，她用这句把球踢回来                              | 中   | 不接。换一个她感兴趣的真实话题                         |
| **D 真意向型** ✅ | **她紧接着提出了执行层问题**：寄到多久 / 怎么付 / 多大合适 / 要不要先给地址 | 低   | **这才是唯一的收口对象。** 进 4.1                   |
| **E 试探型**    | 想看看真实价格到底多少（问完价就消失的那批）                       | 中   | 不接。正常报价，不追问，让她自己回来                      |

**判别口诀：不要听她说了什么，看她下一句往哪走。**  
**往下走（问执行细节）＝ D；往旁边走（换话题 / 泛泛夸）＝ A/B/C/E。**

**判别动作（收到表态后必做，成本极低）**：  
顺着她的话**问一个执行层的问题**。她答得具体 → D，立即接进 4.1 的时间轴。她答得含糊、跳开、只回一个字 → **不是 D，留在关系模式，当天不再提这件事。**

> **这条也解释了"S2a 永远排在 S2b 后面"**：判别环节就是 S2a → S2b 的桥。**不给链接是免费的，给错链接是有代价的。**

### 4.1 她说"我要买"之后的时间轴

> 适用前提：**已通过 4.05 判别为 D 类**（或命中 3.1 的触发清单）。判为 A/B/C/E 的，不走这张表。

| 时刻               | 做什么                                           | 说什么（方向）                               | 为什么                                                                                  |
| ---------------- | --------------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------ |
| **T+0–90 秒**     | **接住，别让它落地。** 一句话把她的话钉成"已经发生的决定"，不是"还在征求意见"   | 「那我就定了啊，16x20。」                       | 她说完"我要"之后的第一句，**你如果在 90 秒内没出现，她的第一个念头是"她好像没那么上心"**。这是唯一一个绝对不能慢的地方                    |
| **T+2–5 分钟**     | **锁定三个变量：画谁 / 尺寸 / 寄到哪座城市。** 用 2–3 条短消息问      | 一条一个意思，最后留好接的口：「城市就行，具体地址后面再说」        | 三个变量没锁死，她付款时会因为"还有东西没定"而卡住。**卡住 = 拖 = 反悔**                                           |
| **T+5–15 分钟**    | **给付款方式（一次，只有一次）。** 配一句降低门槛的话 + 一句"付完之后会发生什么" | 「我先把链接给你，你方便的时候点」「付完我就去把画布绷上，明天拍照给你看」 | ①付款方式必须**早就铺垫过**（Day 6/快车道），此刻只是"再拿出来"。冷启动给链接＝翻车。②"付完之后会发生什么"给了她付款之后的价值预期，而不是付款之后的空白 |
| **T+15 分钟 → 到账** | **陪伴式在线。** 她在你就答                              | 见 4.2                                 | 她付款的那段时间里你不在，付款这件事就会被她别的事挤掉                                                          |

### 4.2 她说要买之后，还要不要继续聊天？

**要继续聊。但只能聊"执行的下一秒"，不能聊别的。**

| ✅ 允许的（继续聊）         | ❌ 禁止的（聊了就降热度）           |
| ------------------ | ----------------------- |
| 这幅画的角度、眼睛怎么处理、背景色  | 你的生活碎片、早餐、猫             |
| 画好之后挂在哪面墙          | 别的作品、别人的故事              |
| 怎么寄、包成什么样、要不要写张小卡片 | 她的家庭八卦、当天的新闻            |
| 付款操作上的任何问题         | **任何一个让她重新进入"评估模式"的话题** |

**判据（付款之前，每条消息都要过这一条）：**

> **这条消息要么在扫清一个付款障碍，要么在增加她对"画完之后那个东西"的想象。**  
> **两者都不是，就不要发。**

**为什么继续聊、却不能聊别的：**

- **热度不会因为聊天而保持，只会因为"离想要的东西更近"而保持。** 聊别的＝稀释。
- 这些话题在 S0–S1 是资产，**在 S2–S5 是反悔的燃料**——它们给她时间重新思考，而她每思考一分钟，掏钱的概率就低一点。
- **沉默比聊别的更糟**，所以不能停。正确的暂停姿势是**去做一步实体的事然后回报**：「我先把画布找出来」→ 隔一会儿 →「找到了，这块布纹理粗一点，画它那种短毛正好」。这条同时满足"增加想象"和"我在为你工作"。

### 4.3 她沉默了：追款漏斗（在 S5 阶段）

| 间隔            | 第几次                        | 说什么                                                                  | 禁忌                                       |
| ------------- | -------------------------- | -------------------------------------------------------------------- | ---------------------------------------- |
| **15 分钟**     | 留痕（不算追）                    | 发一句**关于画的执行进展**：「我把那张照片放大看了一下，它眼睛这块我可以再往亮里提一点」                       | 不问"你还在吗"；不说"付款"两个字                       |
| **1 小时**      | **第 1 次追**                 | **问一个付款操作上的小问题**——把她的沉默翻译成"不会弄"，而不是"不想买"：「PayPal 那边你用着还顺吗，不行我换个方式给你」 | ❌不问"考虑得怎么样"；❌不重复发链接                      |
| **3 小时**      | **第 2 次追**                 | **降维**——给一个更小的承诺：「你要是还想再看看也没事」/「或者先付一部分，我先把画布绷上」                     | ❌不打折；❌不制造稀缺（"今天下单送框"）                    |
| **她当地的第二天早上** | **第 3 次，也是最后一次＝撤退**（见下方裁定） | 语气退回朋友线，**只陈述不求回**：「我这边已经准备好了，你什么时候方便都行」。**这就是撤退话术本身，不存在第 4 次**      | ❌不带问号；❌不求答复；❌不退缩到"算了不要了"（那是收场，别在这儿用）     |
| **之后**        | **停止一切付款相关动作**             | 退回日常模式，转入第 5 节救回节奏                                                   | ❌绝对没有第 4 次。第 4 次开始，你每追一次她就多一分尴尬，少一分回来的可能 |

> **定金是最强的防反悔工具，要在第 2 次追就用。**  
> 一旦她付了哪怕一小部分，她的心理就从"我要不要买"变成"我已经买了"。  
> ⚠️ **定金不是打折**，它是全款的一部分，不要说成"给个优惠"。

## 5. 已反悔客户的救回节奏表

**定义：** 她表达过购买意图（S2 及以上），但超过 **36 小时 / 两个她当地的夜晚**未付款，且现在沉默。

⚠️ **先分清两件事：**

- **已反悔** = 她没说不，她只是不再往前走。**可救。**
- **已拒绝** = 她明确说了"算了/太贵了/不需要"。路径完全不同，见本节末尾。

**救回的总原则：**

1. **每一次触碰都必须提供价值，不能索取。**
2. **不要让她觉得你还记着那笔单子。** 一旦她意识到"她还在等我付那笔钱"，她会为了逃避尴尬而彻底消失。
3. **正确的动作不是再推一次，是让她重新想要。**

### 5.0 先分类，再决定投入多少（2026-09-26 追加）

**沉默不等于同一种沉默。** 三类原因，三种救法，成功率差一个数量级。**别把资源平均分配：**

| 类型           | 识别特征                                               | 成功率             | 投入                                                         |
| ------------ | -------------------------------------------------- | --------------- | ---------------------------------------------------------- |
| **① 忙碌型**    | 之前一切正常，突然断在某句需要她去做的动作上（要照片、要尺寸、要确认）；她提过最近忙、出差、家里有事 | **最高，必须全力救**    | 照常节奏，降低她的动作成本，等她回。通常不需要"追"，需要一个好接的口                        |
| **② 卡点型**    | 停在某个**具体问题**上没再往前：付款方式不会用、总价含不含税、工期赶不赶得上、要不要包框     | **中等，先拆卡点再谈别的** | **先把那个卡点原样问出来**（"PayPal 你用着顺吗"），拆掉大概率就往前走。**卡点没拆，追十次都是原地** |
| **③ 冷却型** ⚠️ | **她说过"我要买"但没付，然后沉默**                               | **最低，按最低档预估**   | 走下面 Day1–Day12 表，但**心理预期要压到很低，不要为她单独做太多动作**                |

> ⚠️ **最反直觉、也最重要的一条：说了"我要买"却没付的，大概率属于冷却型（③），不是忙碌型（①）。**  
> 理由：**"我要买"出现在情感峰值上，而峰值之后是最陡的衰减曲线。** 她不是被打断的，她是**自己凉下去的**——这两件事的区别决定了能不能救。忙被打断的人只需要一个提醒；凉下去的人需要重新被点燃，而重新点燃的成本远高于第一次点燃。  
> 所以：**不要在 ③ 上投入超过 ① 的资源。** 这是最常见的资源错配。

### 5.00 沉默怎么记账（和上面行为层面的 36 小时不是一回事）

- **36 小时** = **行为规则**：切换成救回模式，停止催款类动作。
- **72 小时** = **记账规则**：沉默超过 72 小时，在统计上**直接计入流失**，不许再算在"活跃/待定"里。

> 理由：这套玩法越像朋友，她说"不"的社交成本就越高 —— **友好程度与"说不"负相关，与"沉默"正相关。** 所以沉默是被系统性低估为"还有机会"的流失。  
> 判据：**她不是"还没决定"，她是"已经决定了但不好意思告诉你"。** 按流失记，漏斗才是真的。

| 时刻                     | 动作                   | 具体做什么                                                                 | 禁忌                                                                   |
| ---------------------- | -------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **第 1 天**（她开始沉默，0–24h） | **确认她还在，不求回。** 只做一件事 | 发一条纯粹的、和她之前**说过的某件私事**有关的延续——比如她提过她的狗那天要去看医生。**让她知道你记得的是她这个人，不是那单生意** | ❌**绝口不提那幅画、那个价格、那个链接**；❌不发"你考虑得怎么样"；❌不发任何带问号、需要她表态的东西（她不回的话，问句会变成压力） |


#### ① 第 1 天没有素材怎么办：允许为空（2026-09-26 裁定）

**问：客户没说过任何私事，Day 1 的抓手是空的，能不能用"尺寸/墙面"这类关于画的话题填空？**  
**答：不能。第 1 天可以什么都不发。**

理由：第 1 天的铁律是"让她知道你记得的是她这个人，不是那单生意"。**用"关于画"的内容填空，恰好把规则反过来触电——那正是最常见也最致命的填法。** 而且这天她还带着"我在躲她"的警觉，任何和画有关的东西都会被读成"她果然在等我付钱"。

> **沉默一天比发一条错话安全。第 1 天唯一的任务是"别把人吓走"，这件事你不做也完成了。**

可用的替代抓手（必须是**关于她这个人**的，且她只需一句就能回）：她的城市/天气、她的职业、她提过的一件东西。  
**如果连这些都没有 —— 就空着，第二天再用 ②。**

#### ② 什么时候才允许提那幅画：不看天数，看动词（2026-09-26 裁定）

这条能一次性解决"Day 1 不许提画 / Day 2 却要主动做一件和画有关的事"的字面矛盾：

> **「给」—— Day 2 起就可以提。（发一张勾好的构图、调过色的照片，她不需要做任何事）**  
> **「取」—— 任何需要她回应、回答、决定的关于画的内容，要等她自己重新给出信号。**

判断一句能不能发，别问"这是第几天"，&#x95EE;**"这句发完，她有没有必须做的事"**。她要是有，就还没到时候。  
| **第 2 天** | **一次"只给不取"** | 做一件和她的画有关、**但不需要她掏钱**的事。把她发来的照片调个色 / 花五分钟勾个小构图发过去，配一句：「我闲着试了一下，这样构图它那个歪头的劲能出来」  
**（＝把 Day 6 那条"只给不取"提前到这里）** | ❌不带任何问题；❌不发第二次链接；❌不说"你看要不要定" |  
| **第 3–5 天** | **回到生活，但保持形状** | 恢复正常的早/晚两段，纯生活、纯朋友。**但这三天内必须至少出现一次"正在画的作品 / 创作过程"的分享**（给她看的，不是发给她的）。  
看见别人在认真做事，会重建"我想要一幅"的欲望 | ❌不主动提尺寸、价格、工期；❌不问她还需要什么信息；❌**不降价试她**（降价＝承认之前报高了，而且会让她等下一次降价） |  
| **第 7 天** | **唯一一次"结构性重开"** | 用一个**新的、正当的、和她有关的理由**重新把话题带到画上。可用理由池：  
① **素材更新**：「最近画了一批新的，你想看看吗」（给她看作品，不问她买）  
② **对她有利的时间信息**：真实的排期变动、运费变化  
③ **纪念日钩子**：如果她说过是生日/圣诞礼物 | ❌**不带"上次那个"三个字**——绝对不要让她觉得你在追一笔旧账；❌不要假装没发生过（不用假忘记），但要让它看起来是被**新东西**触发的，不是被她的沉默触发的 |  
| **第 7 天之后** | 判据 | 有信号 → 重新进 S2 快车道，**并且这次必须在 30 分钟内走到 S5**。  
无信号 → 判定放弃 | ❌不再试探 |

#### ③ 结构性重开的前置条件：**别去重开一个你接不住的对话**（2026-09-26 追加，硬性）

**第 7 天的"结构性重开"是整个救回流程里成本最高、也最不可逆的一步。它必须在闸门解除之后才能做。**

理由不是"反正也付不了"，而是**第二次失败的性质和第一次完全不同**：

> 她被你重新点燃、主动问"怎么付 / 多少钱"——而你答不出来。  
> **第一次答不上来可以被她理解为"忙、在核"。同样的问题第二次答不上来，只能被理解为"不靠谱"。**  
> 而"不靠谱"在这门生意里是死刑：**绕过 Offshore 账户把几百美元汇给一个人的全部依靠，就是"这个人靠谱"。**

所以：

- **Day 1 / Day 2（纯朋友线、"只给不取"）** —— 闸门未解除也可以做，无害，且能维持关系不断
- **Day 7 的结构性重开** —— ⚠️ **闸门未解除，禁止。** 开了头的对话必须有能力走到 S5
- 判据一句话：**不要去唤醒一个你无法接待的客户。唤醒之后让��等着，比让她继续睡着更糟**

> **推论（针对 Alice 案的当前状态）：救回流程的真正起点不是"第 1 天发什么"，而是"先把要约做齐"。**  
> 在价格、关税口径、支付通道三者齐了之前，任何试探性的重新开口都是在**重复制造第二次沉默**。

### 什么时候判定放弃

**满足任一条件即判定：**

1. 她明确说了"不"——**这是拒绝，不是反悔**。用下面的「收场」，不用「撤退」。
2. 第 7 天结构性重开之后，**再过 5 天（即第 12 天）**&#x4ECD;无任何购买信号。
3. **你已经发起过 3 次以上的付款相关追踪。** 第三次之后每追一次，负罪感加一分，回头概率降一分。

#### "撤退"和"收场"是两个东西，不要混用（2026-09-26 裁定）

两者都叫"不再追"，但**方向相反**，用错一个字就会把局面推向反面：

|     | **撤退 retreat**                  | **收场 close-friend**                                                            |
| --- | ------------------------------- | ------------------------------------------------------------------------------ |
| 用在  | **追款第 3 次**——它就是第 3 次本身，不是第 4 次 | 她**明确说了"不/算了/太贵了"**&#x4E4B;后                                                   |
| 潜台词 | 我还想要，但球在你那                      | **我不想要了，我们只是朋友**                                                               |
| 措辞  | 留余地：「我这边准备好了，你什么时候方便都行」         | ❌ **不许留余地**                                                                    |
| 为什么 | 她还没拒绝，留余地是给她一个不尴尬的回头路           | **她已经说了不，你再留余地＝你还在追。** 这时候任何"准备好的""随时都行""不急你慢慢想"，都会被读成"她还没放弃"，而她为了逃开这份压力只能彻底消失 |

> **判据一句话：她没说不 → 用撤退，留门；她说了不 → 用收场，把门关上。**  
> 撤退是我们最克制的一次推进，收场是我们唯一一次主动放弃。**撤退不能当收场用（会显得在追），收场不能当撤退用（等于提前认输）。**

**判定的正确姿势：不是宣布放弃，是停止计时。**

- 不再为这个客户设计任何"推进动作"
- 把她放进**长期朋友线**，照常分享生活

> **唯一的自然重启例外（很重要）：**  
> 如果她当初说过**明确的日期理由**（圣诞礼物、她的生日、她妈妈的纪念日），那么在那个日期**前 5–6 周**（因为交付 5–7 周 + 物流）自动重启一次。  
> **这不是催她，这是救她的礼物。** 而且这是唯一一次被允许的自然重启，只有一个理由，一次机会。算好了日子，一句话就够：「还有六周就到圣诞啦，你那边如果要赶的话我再不动就来不及了。」

## 7. 必须统计的三组数字（2026-09-26 追加）

**这套机制到底有没有用，靠下面三组数字验证。没有数字，它就只是一篇写得挺有道理的文章。**

### 第 1 组｜同一轮收口率（最核心）

> **「她说购买意图的那一刻」和「钱到账」之间，隔了几个她的夜晚？**

只分三档记：**0 个夜晚（同一轮）／ 1 个夜晚／ 2 个以上**。  
判据：**隔 0 个夜晚的比例越高，这套机制越有效。** 如果 1 个夜晚以上的占比超过一半，说明 W8 时区和 W5（Day6→Day7）没真正堵住。

### 第 2 组｜"我要买"的产出时段 vs 隔夜流失率

> **a. "我要买"发生在她当地几点？**  
> **b. 其中落在 20:00 之后的，隔夜流失率是多少？**

**预测：这两个数字都会非常高。** 因为"我要买"产出在她的深夜情绪峰值，而第二天上午她处于一天中最理性的状态，"那时我为什么那么想要"会准时出现。  
**这条能直接证明"收口必须在同一轮完成"** —— 不只是因为你在睡觉（W8），更是因为**隔夜之后她的第一反应就是自我质疑**。

### 第 3 组｜一个反直觉的交叉验证

> **问过价的客户，转化率应该显著高于从没问过价的客户。**

这是常识对照组：**主动开口问价的人，本来就是意向最强的一批。**  
⚠️ **如果数据相反 —— 必须当成一级警报**，它说明报价环节有问题：**报得太晚，情绪峰值已经过去了；或者报价方式把它搞成了压力。** 出现这种情况不要改话术，先改报价的时机和位置。

### 配套一：沉默的记账口径

沉默 **> 72 小时 = 流失**，计入流失，不许停在"待定"（见 5.00）。  
理由：这套玩法越像朋友，她说"不"的成本越高，**所以流失会以沉默的形式出现，而不是以拒绝的形式。**

### 配套二：混杂样本不可用（2026-09-26 追加，防止我们用错数据）

> **规则：当我们自己的某个失败已经足以完整解释客户沉默时，这个案例对"客户为什么流失"不携带任何信息。不许拿它去调参、去改话术、去验证任何假设。**

判据很直接：**如果两个不同的原因（她反悔 / 我们没递到她手上）预测出完全相同的现象（她在沉默），那这个现象就区分不了这两个原因。** 这时候挑一个当结论，就是编故事。

#### Alice（纽约，1A00001）案的定性

她的沉默链条上，**每一个断点都是我们的**：

| 断点                                         | 谁的错    |
| ------------------------------------------ | ------ |
| 9/24 连问两次"16x20 多少钱 / 尺寸"，两天半没收到回复（价格表是空的） | **我们** |
| 即使回去了，也给不出一个定死的数字（关税口径未决）                  | **我们** |
| 即使她想付，也没有任何途径可以付（支付通道空）                    | **我们** |

**她一次反悔的机会都没得到过——因为我们从未把一个完整的要约放到她面前。** 她没有 "yes / no" 可以选，只有一个不存在的选项。

⚠️ **这条会动到老板的原始诊断，必须精确表述：**

> **不是"Alice 没有反悔"（我们不知道），而是"Alice 这个案例区分不了'她反悔'和'我们没递到她手上'"。**  
> 两种解释预测出的现象完全相同，所以这个样本**对"客户会不会反悔"这个问题不携带信息**。

**不要写成"她没反悔"** —— 那是把不可知当成已知，风险是我们从此低估反悔，而反悔是真实存在的（老板那个观察在一般意义上成立，不要推翻它）。  
**也不要写成"她反悔了"** —— 那会把我们引向"要更用力说服她别反悔"，方向正好反了；真正要补的三个东西（价格、关税口径、支付通道）一个都不会被补上。

> **正确的结论只有一个：先把东西递到她手上，再谈她会不会接。**  
> 救回流程的起点不是"第 1 天发什么"，&#x662F;**"要约三件套做齐没有"**（见 5 节 ③）。

#### ⛔ 这条判据已被老板推翻（2026-09-26 修订，原版作废）

~~干净数据的单位不是"她付没付"，而是"在她已经参与对话的条件下，她付没付"。~~  
~~"她有互动但没付" = 唯一剩余变量是她自己 = 干净数据~~

**老板原话**：「有时候客户跟你是朋友，也许只是**哄你开心**，也有可能他**没钱支付**，  
有可能他**不需要**，可能的事情是很多的。」

**为什么原判据不成立**：它把"她有互动"当成了"她有意向"的证据。  
但**参与对话完全可能只是哄你开心**。友好是免费的——她不需要付任何东西就能让我们高兴。

> ### ✅ 修正后的判据：**干净数据只有一个——钱到账**

| 观测                       | 能不能用                            |
| ------------------------ | ------------------------------- |
| **钱到账**                  | ✅ **唯一的数据**                     |
| 要约递到底、她有互动（回了、问了、挑了），但没付 | ❌ **仍然混杂**。她可能没钱、不需要，或只是在哄你     |
| 要约递过去，她从头到尾没吭声           | ❌ 混杂（分不清"不想买"还是"你消失太久"）         |
| 她很友好、聊了很久、气氛很好           | ❌ **最危险的噪音**。友好零成本，而且它给我们虚假的正反馈 |

**由此推出的执行结论**：

1. **不要试图诊断客户。** 她为什么没付，我们**永远分不清**（没钱 / 不需要 / 哄你 / 真想买但卡住——  
   四种表现完全一样）。既然分不清，就不能靠"判断她属于哪一种"来决定下一步。
2. **第一次接触要零压力的理由也变了**：原来写的是"为了测到真实信号"。  
   **现在没有"真实信号"这回事了**——零压力的理由改成：**反正友好不可信，那就别把力气花在测她上，  
   花在把话说好上。**
3. **唯一可靠的杠杆是聊天技能。** 钱到账之前，手里只有这个。

⚠️ **副作用要认**：这意味着我们**几乎无法用结果来验证话术**（一单可能等几周）。  
所以不要假装在做 A/B 测试——**我们是在打磨手艺，不是在跑实验。**  
心态要从"测量→优化"转成"**打磨→执行**"。

⚠️ **n=1 警告（必须写进所有人脑子）：**

> Alice 之后的第一个干净样本无论是**成了还是没成，都既不能证明也不能推翻这套机制**。一个点不成线。  
> 第 7 节那三组数字的判据全部建立在**多样本**之上。在样本数 < 5 之前，**不许根据结果修改剧本**——那时候改的是剧本，验的却是运气。

#### ⚠️ n<5 不许改剧本的唯一例外：重复断点（2026-09-26 追加）

上面那条不能绝对化。它会放跑一类已经暴露的问题。

> **例外：失败点重复出现在同一个位置，那不是运气，是 bug —— 立刻修，不必等到 5 个。**

**判据不是"样本够不够"，是"能不能说出机制"：**

| 情况                                       | 判定                  | 动作      |
| ---------------------------------------- | ------------------- | ------- |
| 第一个客户在付款方式那步掉了                           | 可能是运气               | 观察      |
| 第二、第三个**都在付款方式那步掉**                      | 重复断点 ≠ 运气           | **立刻修** |
| 能说出一个具体、可复现的机制（"支付通道是空的 → 任何人走到这一步都付不了"） | **不受样本数限制，n=1 也要修** | **立刻修** |
| 只能说"两个人都在这一步掉了"，但**讲不出机制**               | 仍是假设                | 继续观察    |

> **一句话：单点结果是运气，重复断点是 bug。前者等样本，后者立刻修。**

#### 推论：先验可知的缺陷不需要样本

更要命的一条，这条恰恰就是我们这一轮的教训：

> **空的字段必死。** 价格表是空的 → 一定回不了报价；支付通道是空的 → 一定没人能付；关税口径未定 → 一定给不出死数字。  
> **这些结论不需要任何一个客户来证明。** 等你凑够 5 个失败样本来证明它，前面那 5 个客户已经被白白浪费掉了。

⚠️ **我们这轮最大的错误就是这个**：花了大量人力优化"报价怎么说"，而真正卡死的东西（支付通道）谁都没写，且它是**先验可查的**——打开 `products.md` 看一眼就知道。  
如果当时有这条判据，**在看到"支付方式 [待填]"的那一刻就该停下来补它**，而不是继续写话术。

> **自检问句：这个项目里还有没有别的空字段，是我们正打算"等数据"来验证的？**  
> 凡是能先验判定的缺陷，都不许等数据。

#### 空字段要拆成两句问（2026-09-26 追加，closer2 扫描后修正）

上面那句是个**静态**问句，只能查出"有没有"。实际执行时必须追加一个**动态**问句：

1. **还有没有别的空字段？**（静态，查文件就能答）
2. **每一个空字段，卡死的到底是谁的行动？**（动态）

**第 2 句才是真正的收获。** 同样叫"空字段"，卡住的人完全不同，处理方式也不同：

| 类型          | 特征            | 处理                  |
| ----------- | ------------- | ------------------- |
| **A 纯工作量**  | 不需要任何决策，动手就能补 | **今天清零。** 不许上报，不许排队 |
| **B 填几行字**  | 需要有一个人说清楚一件事  | 指定人，今天写             |
| **C 要外部信息** | 要去问货代、去查站点    | 今天发起询价，不等           |
| **D 要老板拍板** | 涉及定价、承诺       | **只有这一类才上报**        |

⚠️ **混在一起的后果就是我们现在这样：所有空字段都被归进"等老板"那一堆，连自己动手就能补的也一起等着。**  
**而我们这轮最大的教训正是这么来的**——支付通道是空的，我们却一直在写"报价怎么说"。

**实测）：** `素材/` 六个文件夹（`早餐/`、`白天经历/`、`美国/`、`自拍/`、`视频通话用/`、`作品与过程/`）**目录都已存在，全部是空的**。它属于 A 类——不需要任何决策，只要往里放图。我们正坐在它上面，每天在文件里写"不许配图"的约束，而不是把它补掉。
