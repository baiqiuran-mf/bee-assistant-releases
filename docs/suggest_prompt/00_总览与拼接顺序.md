## 关键提醒

- **playbook7d.md 单文件最大**（约 77 KB），每次全量发送，是成本大头。
- **客户 16 字段档案当前并未进入 suggest**（server.js 实际传 `profile: null`），AI 只用了姓名/编号/地区/Day/情绪等基础字段。
- **输出预算**：`max_tokens` = 8192 + (留言数−1)×800，封顶 16000（混元 hy3 推理模型，思考也吃额度）。
