============================================================
  蜜蜂信息采集 · 发新版本到 GitHub（速查）
============================================================

  一句话：以后发新版只要跑「方案 A」那 3 条命令，不用再找教程。

------------------------------------------------------------
  【方案 A】只放安装包（你现在用的方式，★★★★★ 推荐）
------------------------------------------------------------
  代码不传 GitHub，只上传 3 个文件。客户在浏览器点一下下载。

  第 1 步：打包（先改 package.json 里的 version，例如 1.5.0 → 1.6.0）

  第 2 步：传（把下面三个文件名里的版本号改成新的）

      cd /d E:\WorkBuddy-Projects\wa-assistant
      set PATH=%PATH%;C:\Program Files\GitHub CLI
      gh release create v1.6.0 ^
        release\wa-assistant-setup-1.6.0.exe ^
        release\wa-assistant-setup-1.6.0.exe.blockmap ^
        release\latest.yml ^
        --repo baiqiuran-mf/bee-assistant-releases ^
        --title "蜜蜂信息采集 v1.6.0 · 这里写一句话主题" ^
        --notes-file release\NOTES-1.6.0.md ^
        --latest

  第 3 步：验证

      gh release view --repo baiqiuran-mf/bee-assistant-releases

------------------------------------------------------------
  方案 A 的 4 个坑（这次全踩了）
------------------------------------------------------------

  坑 1  项目原本不是 git 仓库 → 报 "fatal: not a git repository"
       已解决（2026-10-08 已 git init + 提交过一次，以后不会再报）

  坑 2  报 "no git remotes found" → 必须在命令里带 --repo 参数
       这样代码就不会被推上去 ✅

  坑 3  config.yaml 含 API key 和代理密码，第一次提交时被带进去了
       已解决：已 git rm --cached config.yaml 并 amend 掉
       ⚠️ 以后别再 git add -A 提交新东西，这个文件已经在 .gitignore 里

  坑 4  132MB 上传要 2~5 分钟，命令行没输出是正常的，别以为卡死了

------------------------------------------------------------
  【方案 B】用浏览器手动传（不想用命令行时）
------------------------------------------------------------
  1. 打开 https://github.com/baiqiuran-mf/bee-assistant-releases/releases
  2. 点右边的 "Draft a new release"
  3. "Choose a tag" 里填 v1.6.0（是新 tag，选 "Create new tag"）
  4. "Select a tag" 上面填标题
  5. 把 3 个文件拖进去：
       wa-assistant-setup-1.6.0.exe
       wa-assistant-setup-1.6.0.exe.blockmap
       latest.yml
  6. 最下面勾 "Set as the latest release"
  7. 点 "Publish release"

------------------------------------------------------------
  【方案 C】一键给客户下载链接（发版本时最实用的）
------------------------------------------------------------
  打开这个页面发给客户，他们在浏览器点一下就能下载：

      https://github.com/baiqiuran-mf/bee-assistant-releases/releases/latest

  不用给客户发 132MB 的文件，也不用装任何东西。
  每次发新版，这个链接自动指向最新版。

------------------------------------------------------------
  【必读】latest.yml 必须和 exe 同一次打包产出
------------------------------------------------------------
  latest.yml 里面记着 exe 的 sha512 校验值。
  手工换 exe 不换 yml → 软件会报"校验失败"然后更新失败。
  永远用打包自动生成的那一份，别手工拼。

------------------------------------------------------------
  软件里怎么验证成功
------------------------------------------------------------
  打开软件 → 设置 → 点「检查更新」→ 应该能看到新版本并能下载。

  如果提示"更新源配置有问题"→ 多半是 latest.yml 没传，或传错了。
  如果提示"校验失败"          → latest.yml 和 exe 不是同一次打包的。
