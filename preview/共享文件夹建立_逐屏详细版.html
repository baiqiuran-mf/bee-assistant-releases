「拒绝访问」到底是什么意思

不是共享没建，是建了但不让你看。Windows 默认「保护性共享」会隐藏共享列表， 不登录对方账号就看不到任何共享名。所以你可能建了共享自己却没发现 —— 别急着重建， 先做下面的步骤 1~3，权限给对了它会自己冒出来。

第 3 步：权限设置（🔴 最容易漏、最关键）

这一步是整个教程的核心。Windows 共享有两个地方都能设权限，而且规则不一样：
  • 「共享」选项卡里的权限 —— 管通过网络访问的人（我们主要靠这个）
  • 「安全」选项卡里的权限 —— 管所有访问者，包括本机用户
两个都要设，而且要让它们不打架。下面分开讲，先设共享权限（第 4 步）再设安全权限（本步）。

第 5 步：开防火墙

为什么这步不能跳：Windows 防火墙默认阻止入站的文件共享连接。 前面 4 步都做对了，如果没有这一步，从 46 这台连过去还是会显示「找不到网络路径」或超时。
9先确认网络是「专用」还是「公用」

这一步决定后面怎么设。如果你的网络是「公用」，文件共享会被防火墙挡得更严。

图形界面看：设置 → 网络和 Internet → 状态 → 找到当前网络（比如「以太网」）→ 看右边写的是 「专用网络」还是「公用网络」。

命令行看（推荐，更准）：在 204 上按 Win + X → 选「终端(管理员)」或「Windows PowerShell(管理员)」，然后：

Get-NetConnectionProfile | Select-Object InterfaceAlias, NetworkCategory
管理员: Windows PowerShell
InterfaceAlias　NetworkCategory
-----------　----------------
以太网　　　　　　Private　← 专用（好）
WLAN　　　　　　　Public　　← 公用（要改）

如果是 Public（公用），先改成 Private（专用）：

Set-NetConnectionProfile -InterfaceAlias "以太网" -NetworkCategory Private

把 "以太网" 换成上一步显示的实际接口名（InterfaceAlias 那一列）。

方法 B：一条命令搞定（推荐，最快）

在 204 的管理员 PowerShell 里跑：

# 放行文件和打印机共享（仅专用网络）
Set-NetFirewallRule -DisplayGroup "File and Printer Sharing" -Enabled True -Profile Private

# 放行网络发现（可选，但建议开，不然"网络"里看不到这台机器）

💡 怎么知道跑成功了：没有任何输出就是成功了。 想确认的话可以再跑一次查询命令： 
Get-NetFirewallRule -DisplayGroup "File and Printer Sharing" |
  Where-Object Enabled -eq True | Select-Object DisplayName, Profile
能列出规则就说明已启用。

第 7 步：验证（在这台 46 上做）

上面 6 步做完后，回到你现在这台机器（192.168.10.46），跑下面 3 条命令。 这是确认真的通了，不是"应该通了"。

验证 ①：能看到共享名吗

net view \\192.168.10.204

成功的样子：列出一个表格，里面有 wa-update，状态是 共享 或 Disk。

还是「拒绝访问」：说明第 3 步或第 4 步的权限没生效，回去检查「访问权限」那一栏是不是还是「无」。

验证 ②：能列出文件吗

dir \\192.168.10.204\wa-update

成功的样子：显示 File Not Found 或者列出文件（现在应该是空的，因为还没放文件）， 但关键是不要出现「拒绝访问」。

提示「拒绝访问」：权限还没给对。最可能是漏勾了「列出文件夹内容」。

验证 ③：映射成盘符（更方便，后面传文件用）

net use Z: \\192.168.10.204\wa-update
dir Z:
net use Z: /delete

成功的样子：命令成功完成，然后 dir Z: 能列出内容。

映射后传文件就方便了：直接 copy xxx Z:\ 就行，不用每次写全路径。

验证 ④：放个测试文件试试写权限

echo test > \\192.168.10.204\wa-update\test.txt
dir \\192.168.10.204\wa-update
del \\192.168.10.204\wa-update\test.txt

这步测的是你自己有没有写权限。如果你给的是「读取」权限，客户端下不了， 但你自己要能写（以后要往里放新版本）。

如果这一步失败了，说明你给 Everyone 的权限太严了。 最简单的办法：先给 Everyone 完全控制，等所有文件都放好了，再改回「读取」。
