### 登录（1 分钟）

**方法 A：刚弹出的浏览器页面**
1. 看浏览器有没有新标签页打开（标题是 "Sign in to GitHub"）
2. 登录 `baiqiuran-mf` 账号
3. 点绿色 **Authorize github** 按钮
4. 回到命令行，会显示登录成功

**方法 B：如果浏览器没自动打开，手动跑这条**
打开「终端」或「命令提示符」，粘贴：
```
"C:\Program Files\GitHub CLI\gh.exe" auth login --hostname github.com --git-protocol https --web
```
然后按提示选：
- `What account do you want to log into?` → 选 **GitHub.com**
- `What is your preferred protocol?` → 选 **HTTPS**
- `Authenticate Git with your GitHub credentials?` → 选 **Yes**
- `How would you like to authenticate GitHub CLI?` → 选 **Login with a web browser**
- 会显示一个一次性验证码（如 `XXXX-XXXX`）→ 复制
- 浏览器打开 `https://github.com/login/device`，粘贴验证码 → Authorize

**验证登录成功：**
```
"C:\Program Files\GitHub CLI\gh.exe" auth status
```
看到 `Logged in to github.com account baiqiuran-mf` 就成了。

## 如果报错

| 报错 | 怎么办 |
|---|---|
| `HTTP 404` | 仓库名错了，或登录的账号不是 baiqiuran-mf |
| `HTTP 403` | 权限不够，重新登录时确认选的是 baiqiuran-mf 账号 |
| `release already exists` | 已经有 v1.5.0 了，加 `--clobber` 覆盖 |
| `file not found` | 没 `cd` 到项目目录，或文件名拼错 |
| 客户端说「已最新」但有新版 | Release 没勾 `--latest`，或 `latest.yml` 没传上去 |

---

## 两个必须知道的坑

1. **`latest.yml` 和 exe 必须是同一次打包的产物** —— yml 里记着 exe 的 sha512 校验值，
   手工换 exe 不换 yml 会**校验失败**。
2. **`latest.yml` 必须每次都传** —— 软件靠它知道最新版是哪个版本。漏了就更新不了。
