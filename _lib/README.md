# 
  WhatsApp 客户助理

  多账号消息监听 + 中文回复建议。数据全部存本地，只给建议，发送永远人工。

---

## 
  一、硬边界

  这个工具不具备自动发送能力，代码里没有实现任何发送接口。
  它只做四件事：收消息、存本地、翻译成中文、给中文建议。

---

## 
  二、跑起来

```

  ```bash
  npm install
  npm start
  ```

```

  如果 `better-sqlite3` 编译报错，改用 Node 内置 sqlite：

```

  ```bash
  npm run start:builtin
  ```

```

  然后：

  终端弹出二维码，用手机 WhatsApp 扫（扫一次，登录态存本地，以后自动进）

  扫码后自动同步最近 30 个对话的历史消息（不翻译、不置为待办，省钱）

  打开 `http://127.0.0.1:8787`

  先只开 1 号账号：`config.yaml` 里账号 2–5 的 `enabled` 保持 `false`，跑顺了再开。

  自测：`npm test`（70 项，不需要联网、不需要 API key）

## 
  三、编号规则

```

  ```
  3A00050
  ││└── 5 位序号，00001 ~ 99999
  │└─── 字母段，A 用满 99999 后进 B
  └──── WhatsApp 账号号，1–5
  ```

```

  编号绑定的是对方的 WhatsApp 号码，不是昵称——他改名也不影响

  编号一经分配永不回收、永不复用

  同一个人加了你 1 号和 3 号？会是两个编号（`1A00001` 和 `3A00005`），系统提示疑似重复，你决定合不合并

  举例：Mike，旧金山，+1534685245，是 3 号账号的第 50 位客户 → `3A00050`，此后与 Mike 永久绑定。

## 
  四、每个客户一份档案文档

  除了数据库，每个客户还会生成一份可直接打开看的 Markdown 文档：

```

  ```
  data/customers/Mike_旧金山_3A00050.md
                 └名称┘└地区┘└─ 编号 ─┘
  ```

```

  文档开头固定是客户信息头：

```

  ```markdown
  # Mike · 旧金山 · 3A00050

  | 项目 | 内容 |
  |---|---|
  | 编号 | **3A00050** |
  | 姓名 | Mike |
  | 地区 | 旧金山 |
  | 时间差 | 当地时间比北京时间晚 15 小时（当地 UTC-7） |
  | 时区 | America/Los_Angeles |
  | 电话号码 | 1534685245 |
  | 加好友时间 | 2026-09-23 03:11 |
  | 所属 WhatsApp 账号 | 3 号 |
  | 当前阶段 | Day 2 |
  | 情绪 | 有兴趣 |
  ```

```

  下面是客户档案（生成建议时自动抽取填充）和完整对话记录（英文原文 + 中文翻译）。

  几个细节：

  时差自动算：填了地区就自动识别时区并算与北京的时差，美国夏令时会自动跟着变（旧金山夏天晚 15 小时、冬天晚 16 小时）

  改名会重命名文件：Mike 改成 Mike Zhang，文件自动变成 `Mike Zhang_旧金山_3A00050.md`，编号不变

  文档随时可以直接编辑，也可以整份丢给 AI 读

## 
  八、目录结构

```

  ```
  wa-assistant/
  ├── config.yaml          配置（账号、代理、模型、知识库）
  ├── src/
  │   ├── ids.js           编号生成器
  │   ├── db.js            数据库 + 待处理状态机
  │   ├── customerDoc.js   每个客户一份档案文档
  │   ├── ai.js            可插拔 AI 客户端
  │   ├── knowledge.js     知识库按需加载
  │   ├── session.js       浏览器会话（反检测 + 代理隔离）
  │   ├── server.js        本地 HTTP + SSE 推送
  │   └── main.js          入口
  ├── public/              界面（三栏）
  ├── knowledge/           人设、红线、范例、产品、故事
  └── data/
      ├── assistant.db     你的全部客户数据（定期备份这个）
      ├── customers/       每客户一份档案文档：名称_地区_编号.md
      └── media/           压缩后的图片
  ```

```

  备份就是复制 `data/` 整个目录到移动硬盘。
