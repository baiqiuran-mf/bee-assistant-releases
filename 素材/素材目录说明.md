### 01 画布/ `canvas` — 6 张

**这个目录解决什么问题**：客户下单后最大的心理活动是"她是不是拿去打印了 / 是不是根本还没动"。空白→刷底→上底色这条链，是唯一能让客户自己算出"时间真的在过去"的证据。

| 文件名 | 具体拍什么 | 拍摄要求 |
|---|---|---|
| `canvas-01-roll-YYYYMMDD.jpg` | 未裁的亚麻整卷，靠墙斜放，近拍能看到编织纹 | 窗侧光斜打，能看出纹理凹凸；半米距离勿拉太远 |
| `canvas-02-stretch-YYYYMMDD.jpg` | 正在绷布：一只手拉布、一只手拿钉枪/夹子压边 | 露**两只手**不露脸，袖口可以有颜料 |
| `canvas-03-blank-YYYYMMDD.jpg` | 绷好钉好的空白框立墙边，正面平拍四角齐全 | 正对画面，手机与画平行，不要透视变形 |
| `canvas-04-gesso-YYYYMMDD.jpg` | 刷底料中途：一半刷过一半没刷，湿痕反光明显 | 关键：**必须能看到湿反光**，干了就白拍 |
| `canvas-05-primed-YYYYMMDD.jpg` | 刷完晾着的白底，能看出刷子走向 | 干透后拍，侧光45°，笔痕要有影子 |
| `canvas-06-undertone-YYYYMMDD.jpg` | 上过一层薄底色（土红/暖灰/群青皆可）， **这是最重要的一张** | 侧光，能看出薄薄的透明层，边缘留明显的框角 |

**拍摄要求（通用）**
- 光线：只用窗口自然光，窗帘散一下。**禁止闪光灯**（正面打光画布会白成一片，像产品图）
- 露脸：**一律不露脸**；可以露手、露手腕、露围裙下摆
- 文字：**画面内不带任何中文印刷字**（国产底料桶、胶带上的字都不行，转角度避开或撕标签）

**话术场景——每张配哪句（英文发给客户）**

| 图 | 场景标签 | 发出时配的那一句（EN） |
|---|---|---|
| 02 | 进度同步 | "Stretched this one this morning — still smells like raw linen." |
| 04 | 进度同步 | "Half-way through priming. The wet part goes matte when it dries." |
| 05 | 进度同步 | "Primer's dry. Tomorrow I block in the background." |
| **06** | **进度同步** | **"Put a warm undertone down yesterday — it's been drying all day, so I can start the fur tomorrow."** ← 这就是你说的"这块底色晾了一天"，配 **canvas-06** |
| 01 | 报价支撑 | "I use linen, not cotton. It costs more but it doesn't sag over time." |

### 02 静物/ `still` — 5 张

**这个目录解决什么问题**：最低成本、最低压力的"她还活着、还在画"信号。不需要任何进度，每天都能发，用完还能重复用。

| 文件名 | 具体拍什么 | 拍摄要求 |
|---|---|---|
| `still-01-palette-YYYYMMDD.jpg` | 用过的木调色板：边缘有混色残留，两坨颜料还没干 | 自然光，俯拍略斜；不要擦干净，脏才对 |
| `still-02-tubes-YYYYMMDD.jpg` | 七八支颜料管随意散着，管口有干颜料 | 商标朝外但**画面里不能有中文**；错落摆放，不要排成一排 |
| `still-03-brushes-YYYYMMDD.jpg` | 笔筒里插的一把笔，笔尖有残留颜色 | 平视或略俯，毛/貂毛笔要看出笔型 |
| `still-04-jar-YYYYMMDD.jpg` | 洗笔油壶/玻璃杯，底部一层沉淀色 | 逆光或侧逆光，玻璃通透感 |
| `still-05-window-YYYYMMDD.jpg` | 工作台一角：窗 + 茶杯 + 颜料 + 自然光（猫可以入画） | 晨光或午后光最好；这张当"朋友圈封面"用 |

**拍摄要求**
- 光线：自然光，越"随意从旁边照过来"越好；严禁产品图式的正面补光
- 露脸：不露脸
- 排版：**不要摆成商品陈列**，乱一点才像真的。排得越整齐，越像从别人那里下的图

| 01 | 日常寒暄 | "My palette from today. I never fully clean it — that's how colors stay consistent." |
| 02 | 日常寒暄 / 实力证明 | "These tubes are almost empty. Time to restock before your piece." |
| 03 | 日常寒暄 | "Cleaning brushes. The most boring 20 minutes of every day." |
| 05 | 日常寒暄 | "Morning light in the studio. Best two hours of the day for painting." |

### 03 工作桌面/ `desk` — 5 张

**这个目录解决什么问题**：**这是整个素材库里性价比最高的目录。** 客户怀疑对面不是真人（疑虑 #6），最有效的回答不是自拍，是"一张看见有一双手正在干活的桌面"。

| 文件名 | 具体拍什么 | 拍摄要求 |
|---|---|---|
| `desk-01-overview-YYYYMMDD.jpg` | 工作台全景：画架一角 + 颜料 + 抹布 + 手机 + 杯子，**不要太整齐** | 略高于桌面 30–50cm 俯拍，自然光 |
| `desk-02-hands-YYYYMMDD.jpg` | 手持笔调色的瞬间，指腹带颜料 | 只露手到手腕，对焦在笔尖，背景虚化 |
| `desk-03-palette-hand-YYYYMMDD.jpg` | 一只手端调色板 + 一把笔，袖口有颜料渍 | 同上，可露围裙 |
| `desk-04-detail-YYYYMMDD.jpg` | 画面局部 + 手 + 笔尖同框（**只能用你自己的练习稿或已交付作品**） | 微距/近距，能看清笔触堆叠 |
| `desk-05-endofday-YYYYMMDD.jpg` | 收工状态：脏抹布、泡着的笔、油壶、窗外天已暗 | 傍晚拍，色温偏暖反而加分 |

**拍摄要求**
- 必须有**"正在用"的痕迹**：脏抹布、纸巾团、喝了一半的杯子、翻开的颜料盒。桌面太干净 = 摆拍
- 露脸：**不露脸**（desk 系列全部不露脸，露脸只归 `资质/`）
- 禁止：不得出现**另一位客户的画**（哪怕只是局部）——这是最容易踩的坑，见第 6 节

**话术场景**

| 图 | 场景标签 | 配那一句（EN） |
|---|---|---|
| 01 | 真人证明 | "This is my desk right now. Not tidy, sorry." |
| 02 | 真人证明 / 进度同步 | "Mixing the exact color of his nose right now." |
| 04 | 实力证明 | "This is why oil takes weeks — it's layer over layer, not one pass." |
| 05 | 日常寒暄 | "Done for today. My back says stop." |

### 04 成品/ `done` — 8 张（长期目标 15+）

**这个目录解决什么问题**：成交前唯一的硬实力证据。客户在"我想买"和"她值不值这个价"之间，看的就是这里。

| 文件名 | 具体拍什么 | 拍摄要求 |
|---|---|---|
| `done-01-dog-YYYYMMDD.jpg` | 狗肖像正面，能看见整个头 + 一点身体 + 画布厚度 | 平视正对，手机与画面平行；**务必干透后拍** |
| `done-02-cat-YYYYMMDD.jpg` | 猫坐姿全身 | 同上 |
| `done-03-eye-YYYYMMDD.jpg` | 眼睛局部微距 | 微距，能看见高光点和虹膜层次 |
| `done-04-fur-YYYYMMDD.jpg` | 毛发笔触微距 | 侧光，让笔触有立体阴影——**这张是打消"是不是喷绘"的关键** |
| `done-05-twopets-YYYYMMDD.jpg` | 两只宠物同框一张画布（客户高频问能不能画两只） | 同上 01 |
| `done-06-portrait-YYYYMMDD.jpg` | 人物肖像（成人） | **必须已取得本人同意**；未成年人一律不发 |
| `done-07-inroom-YYYYMMDD.jpg` | 画作挂/摆在家居环境（沙发、壁炉、书架旁） | 环境要干净、中性；让客户想象成品放自己家 |
| `done-08-thickness-YYYYMMDD.jpg` | 画布侧面/厚度特写（含绷边、是否已装外框） | 侧光、浅景深 |

**拍摄要求**
- 光线：散射光最保险。直射阳光会让颜料反光成白点
- **必须干透**：湿画表面反光明显，客户会以为作品没干就发货
- 变形：不要用手机广角端；画面四边要保持矩形
- 签名：可以带本人的真实签名，但**所有成品图上的签名必须是同一个写法**

### 05 包装/ `pack` — 6 张（一次拍完，成序列）

**这个目录解决什么问题**：跨境运输是报价阶段最大的隐含阻力。客户不问不代表不担心。这个目录的回答是"我寄过很多次了"。

| 文件名 | 具体拍什么 | 拍摄要求 |
|---|---|---|
| `pack-01-glassine-YYYYMMDD.jpg` | 画刚包上硫酸纸/蜡纸，能看出画还在里面但已覆盖 | 画面被遮住没关系，重点是"有做隔离" |
| `pack-02-bubble-YYYYMMDD.jpg` | 气泡膜包好，四角加护角 | 能看到角包起来 |
| `pack-03-foam-YYYYMMDD.jpg` | 放入纸箱、四周填充完 | 从上往下俯拍箱内 |
| `pack-04-crate-YYYYMMDD.jpg` | 外箱/木箱，拍到大致尺寸感 | 旁边放个常见物体做大小参照更好 |
| `pack-05-tape-YYYYMMDD.jpg` | 封箱 + 加固胶带的特写 | 细节有力，比全景更可信 |
| `pack-06-label-YYYYMMDD.jpg` | **唯一允许出现文字的一类素材**：只留 "FRAGILE" / 国际面单的大致外形，**单号、条码、地址、电话、二维码一律糊掉** | 见下方⚠️ |

⚠️ **pack-06 是本目录唯一有风险的一张。** 做法：手拿着包裹、拇指压住地址栏拍，或拍完用手机编辑把地址条码涂掉。**裸面单（能看清任何一行字）禁止入库。**

**拍摄要求**
- 光线：室内常光即可，不必讲究；粗糙真实反而像发货现场
- 露脸：可露手，不露脸
- 一次做齐：拿一张真实的画完整演练一遍，一口气拍完 6 张，比事后零碎补更像真的

## 5. 通用拍摄规范（所有目录适用）

| 项 | 标准 |
|---|---|
| 设备 | 手机原生相机，**开网格线**，先擦镜头 |
| 光线 | 优先窗口散射的自然光；**禁用闪光灯正面直打** |
| 滤镜 | **一律关掉**。不美颜、不换滤镜、不加相框边框 |
| 构图 | 手机与被摄物平行；地平线/画边保持横平竖直 |
| 格式 | 只收 `.jpg`。不收 HEIC（读取不便）、不收截图、不收网图 |
| 尺寸 | 导出长边 **≤1600px**，单文件 **≤500KB**（WhatsApp 会二次压缩，先压好更清晰） |
| EXIF | **入库前必须剥离定位信息**：Windows 右键文件 → 属性 → 详细信息 → "删除属性和个人信息" |
| 一致性 | 同一块画布、同一只猫、同一个人，前后镜头里必须**是同一个**（客户会比对） |

## 6. 禁止出现在素材里的东西 ★

> 这一节是硬约束。**任何一张图只要命中下列任一条，不许入库、不许发出。**

### A. 隐私 / 可定位（最高风险）
- ❌ **快递面单上的任何可读信息**：姓名、电话、详细地址、单号、**条形码/二维码**（条码可被机器读出）
- ❌ 手机/平板/显示器屏幕上的内容：未读消息、别的客户名字、付款页面
- ❌ 门牌号、路牌、小区名、快递柜、外卖袋、停车票
- ❌ 照片 **EXIF 里的 GPS 定位**（必须剥离，见第 5 节）
- ❌ 能反查出厦门具体地址的一切：窗外独特地标、自家楼下门面
- ⚠️ 尺度：人在中国厦门这件事不用藏，本身就是人设的一部分；**但具体到门牌、店铺、 identifiable 的地址一律不许**

### B. 中文印刷 / 品牌露出
- ❌ 中文招牌、菜单、快递袋上的中文、国产颜料桶的中文标签
  → 处理办法：转角度避开、撕标签、或换用英文标签的产品拍摄
- ❌ 他人品牌 logo（包括朋友品牌、画材以外的品牌）
- ❌ 别人的**网店名、水单、价签**：会让客户警觉"她是不是二手倒卖"

### C. 版权 / 他人作品
- ❌ **不是自己画的任何画**（名师作品、同学作业、网图、AI 生成图，一律禁止）
- ❌ **另一位客户的委托作品，哪怕只露一个角**——这是最常踩的坑，除非该客户已明确同意公开
- ❌ 网上的参考照片原图（哪怕只是你用来对照的客户发来的图之外的图）
- ❌ **人物肖像中未成年人的面部**——一律不发，无任何例外

### D. 人设一致性风险
- ❌ **他人的手、他人的身体部位**——客户会把这张手和那天 Studio 照片里的手放在一起比
- ❌ 不是同一个人 / 不同时期的脸差别过大
- ❌ 网上买的"素材图""摆拍照""AI 人像"——客户会追问细节，一问全露
- ❌ 与你已说过的事实打架的东西：说"我不养猫"却出现猫；说"刚搬进工作室"却出现堆满旧画的架子

### E. 商业/沟通得体
- ❌ 明显是别人价格的聊天截图、支付截图
- ❌ 过度整洁的产品图式摆拍（颜料管精心排成一排、画面一尘不染）——穿帮点最高
- ❌ 带日期/时间戳水印（与客户的时间线会对不上）

## 8. 命名规则

```
{目录英文前缀}-{两位序号}-{英文关键词}-{YYYYMMDD}.jpg
```

| 目录 | 前缀 | 示例 |
|---|---|---|
| 画布 | `canvas` | `canvas-06-undertone-20260926.jpg` |
| 静物 | `still` | `still-01-palette-20260926.jpg` |
| 工作桌面 | `desk` | `desk-02-hands-20260926.jpg` |
| 成品 | `done` | `done-04-fur-20260926.jpg` |
| 包装 | `pack` | `pack-04-crate-20260926.jpg` |
| 资质 | `studio` | `studio-07-portrait-20260926.jpg` |

**硬性约束**
- 只用 **小写 a–z、数字、连字符**；**禁止空格、中文、括号、中文标点、emoji**
- 日期 = **拍摄当天**，不是入库当天
- 同一天重拍用 `-b` 后缀：`canvas-06-undertone-20260926-b.jpg`
- 序号按拍摄先后的**自然流水**，不要留空号
